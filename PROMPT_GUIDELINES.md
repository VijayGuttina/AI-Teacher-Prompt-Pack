# AI Teacher Prompt Library
## Prompt Authoring Guidelines

**Version:** 1.0
**Status:** Approved Standard
**Applies To:** All prompt packs within this repository

---

# Purpose

This document defines the mandatory standards for creating prompts within the AI Teacher Prompt Library.

Every prompt must follow the same structure, writing style, formatting conventions and quality standards to ensure consistency across all books.

These standards are mandatory.

---

# Design Principles

Every prompt should be:

- Practical
- Comprehensive
- Classroom-ready
- Copy-and-paste ready
- Curriculum-aware
- Age-appropriate
- Teacher-friendly
- Adaptable
- Accurate
- Time-saving

The teacher should be able to copy a prompt into ChatGPT without needing to significantly rewrite it.

---

# Core Prompt Structure (Mandatory)

Every prompt must contain the following sections in the exact order shown below.

## 1. Prompt Number

Example:

Prompt 001

Prompt 142

Prompt 387

Prompt numbering must be unique within each book.

---

## 2. Prompt Title

Provide a concise, descriptive title.

Good examples:

Create a Complete Guided Reading Lesson

Generate Differentiated Maths Questions

Write End-of-Year Reports

Avoid vague titles such as:

Lesson Prompt

English Prompt

Worksheet Generator

---

## 3. Purpose

A short paragraph explaining:

- when to use the prompt
- why it is useful
- expected outcome

This section is for the reader.

It is NOT copied into ChatGPT.

Recommended length:

40–80 words.

---

## 4. Prompt

Everything below this heading is copied directly into ChatGPT.

Every prompt must contain the following seven sections.

---

# ROLE

Tell ChatGPT who it should become.

Use highly specific educational expertise.

Good examples:

You are an outstanding primary mathematics teacher, curriculum specialist and instructional designer.

You are an experienced SENCO specialising in inclusive education and adaptive teaching.

Avoid generic roles such as:

"You are a teacher."

---

# CONTEXT

Provide sufficient classroom context.

Typical information includes:

- Year group
- Subject
- Topic
- Lesson duration
- Curriculum
- Previous learning
- Class size
- Ability profile
- SEND
- EAL
- Resources
- Assessment focus

Where possible, present these as editable fields.

Example:

Year Group:

Topic:

Learning Objective:

Lesson Duration:

Resources Available:

---

# TASK

Describe exactly what ChatGPT should produce.

Use precise verbs such as:

Create

Generate

Design

Develop

Write

Plan

Evaluate

Analyse

Avoid vague wording such as:

"Help me."

---

# REQUIREMENTS

This is the largest section.

Specify everything that must appear.

Examples:

Learning objectives

Success criteria

Teacher modelling

Worked examples

Differentiation

Challenge activities

Misconceptions

Vocabulary

Assessment opportunities

Homework

Reflection

Extension

Teacher notes

Resource list

Cross-curricular links

Real-world examples

The more explicit the requirements, the better the output.

---

# OUTPUT FORMAT

Tell ChatGPT exactly how to organise the response.

Examples:

Lesson overview table

Step-by-step sequence

Checklist

Rubric

Bullet points

Markdown tables

Planning template

Parent letter

Report comments

Avoid leaving formatting unspecified.

---

# QUALITY CHECKS

Every prompt must instruct ChatGPT to review its response before presenting it.

Minimum checks include:

- Age appropriate
- Curriculum aligned
- Practical
- Complete
- Accurate terminology
- No duplicated content
- Clear teacher language

Additional checks should be added where appropriate.

Examples:

Safeguarding

Health and safety

Scientific accuracy

Mathematical accuracy

Historical accuracy

Accessibility

Inclusivity

---

# OPTIONAL CUSTOMISATION

Provide optional fields allowing teachers to personalise the prompt.

Typical examples:

School name

Curriculum

Lesson duration

Class size

Topic

SEND profile

EAL profile

Ability range

Resources

Teaching style

Behaviour policy

Marking policy

Homework expectations

These fields should remain optional.

The prompt should still function if left blank.

---

# Pro Tip

After every prompt, include one practical tip for getting even better responses.

Example:

"For even more tailored outputs, attach your existing lesson plan and ask ChatGPT to align the response with your school's planning format."

Recommended length:

30–80 words.

This section is NOT copied into ChatGPT.

---

# Related Prompts

At the end of every prompt include:

Related Prompts

Prompt XXX

Prompt XXX

Prompt XXX

These references should connect similar prompts across the book.

---

# Prompt Length

Recommended prompt length:

600–1,500 words.

Complex planning prompts may exceed this where appropriate.

Avoid artificially short prompts.

---

# Writing Style

Every prompt should be:

Professional

Clear

Specific

Action-oriented

Friendly

Consistent

Use UK English spelling throughout.

Examples:

organisation

behaviour

modelling

specialisation

Avoid American spelling.

---

# Educational Standards

Where relevant, prompts should align with:

- National Curriculum for England
- Early Years Foundation Stage Framework
- Ofsted Education Inspection Framework
- Rosenshine's Principles of Instruction
- Cognitive Load Theory
- Retrieval Practice
- Formative Assessment
- Adaptive Teaching
- Inclusive Practice
- Universal Design for Learning (UDL)
- Metacognition
- Bloom's Taxonomy (where appropriate)

Do not force references where they are not relevant.

---

# AI Behaviour

Prompts should encourage ChatGPT to:

Think step-by-step.

Explain reasoning clearly.

Avoid hallucinating facts.

Identify assumptions.

State limitations where necessary.

Request clarification if critical information is missing.

Produce practical outputs.

---

# Prompt Quality Checklist

Before a prompt is approved, verify that it:

✓ Uses the standard structure

✓ Contains all mandatory sections

✓ Is copy-and-paste ready

✓ Includes sufficient context

✓ Defines a clear task

✓ Specifies output formatting

✓ Includes quality checks

✓ Includes optional customisation

✓ Includes a Pro Tip

✓ Includes Related Prompts

✓ Uses UK English

✓ Is free from ambiguity

---

# Version Control

All prompts should be updated through Git version control.

Major structural changes should increment the document version.

Minor wording improvements should be documented in the repository changelog.
