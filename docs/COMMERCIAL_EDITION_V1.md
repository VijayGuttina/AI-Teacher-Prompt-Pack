# AI Teacher Prompt Pack
# Commercial Edition V1

**Status:** Commercial production
**Edition:** Primary Teacher Prompt Pack V1.0
**Purpose:** Convert the completed primary-teacher prompt library into a concise, practical, sellable teacher resource without requiring the entire master library to be completed first.

---

## Product Decision

The master repository is a reusable prompt library. The commercial PDF is a curated product derived from that library.

**The commercial edition does not need every workflow in the master architecture.**

Do not continue authoring large families solely to satisfy a numerical target such as 100 workflows per module.

The first commercial edition should prioritise usefulness, breadth, clarity and teacher usability over exhaustive coverage.

The remaining master-library workflows can be developed later as V2 expansion content.

## Curation Rules

The commercial edition should contain the strongest prompts, not every prompt.

Select prompts that satisfy most of the following:

1. Solves a real teacher problem.
2. Saves meaningful preparation time.
3. Produces a useful first-pass output.
4. Requires little or no iteration.
5. Is clearly different from neighbouring prompts.
6. Works across multiple year groups where appropriate.
7. Has clear editable variables.
8. Is safe and professionally bounded.
9. Preserves teacher judgement.
10. Demonstrates the value of the wider library.

Avoid:

- Near-duplicate prompts
- Prompts that merely rephrase another workflow
- Excessive metadata inside the main prompt body
- Huge prompts that are difficult to copy or understand
- Artificially increasing prompt counts
- Prompts whose main purpose is demonstrating that AI can produce text

## Commercial Prompt Presentation

Each commercial prompt should be presented in a compact teacher-friendly format:

### Prompt Number and Title

**Best for:** concise description

**Use when:** practical situation

**Difficulty:** Beginner / Intermediate / Advanced

**Copy and paste:**

```text
[Prompt]
```

**Example input:**

[Short realistic example]

**Example output:**

[Short representative excerpt]

**Teacher tip:**

[One practical tip]

**Related prompts:**

[Prompt IDs]

The master-library metadata remains available in the source repository but should not overwhelm the commercial reading experience.

Initial commercial target:

## Version 1 Scope Decision

Assessment authoring is paused after the currently completed families.

Do **not** continue AS-21 to AS-100 merely to complete the framework numerically.

The completed library is sufficient to begin commercial production.

Future assessment workflows can become V1.1/V2 expansion content if customer demand demonstrates a need for them.

## Production Sequence

1. Freeze commercial scope.
2. Curate the strongest existing prompts.
3. Write the commercial front matter.
4. Reformat selected prompts for the commercial reading experience.
5. Build the subject and task indexes.
6. Assemble the Markdown commercial master.
7. Generate DOCX.
8. Generate A4 PDF.
9. Review PDF layout and copyability.
10. Final commercial QA.
11. Version as V1.0.0.
12. Create release artefacts.

---

## Definition of Done

The commercial V1 is ready when:

- The book has a coherent teacher-first structure.
- At least 120 genuinely useful prompts are included.
- Prompts are curated rather than duplicated.
- The strongest completed subject coverage is represented.
- Assessment is sufficiently represented without requiring all 100 planned workflows.
- Front matter is complete.
- Navigation is complete.
- Prompt numbering is sequential.
- UK English is used.
- No em dashes are used.
- Privacy, safeguarding and professional boundaries are clear.
- PDF prompts are easy to copy.
- A4 digital/printable layout works.
- DOCX is generated from the same Markdown source.
- PDF and DOCX pass final editorial and layout QA.
