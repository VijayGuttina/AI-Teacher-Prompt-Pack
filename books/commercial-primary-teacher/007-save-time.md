# Part 7: Save Time

Workflows for turning material you already have into useful teaching resources.

---

## Commercial Prompt 118: Turn notes into a lesson plan

**Best for:** Converting rough teacher notes into a coherent lesson.

**Difficulty:** Beginner

**Copy and paste:**
```text
Turn the notes below into a practical lesson plan for [YEAR_GROUP] [SUBJECT]. Preserve the teacher's intended content and priorities. Add a clear learning objective, prerequisite retrieval, explanation/model, guided practice, independent task, assessment check, timings and resources. Do not invent curriculum requirements. Clearly mark any assumption you have made.

NOTES:
[PASTE NOTES]
```

**Related prompts:** 001, 119, 120

---

## Commercial Prompt 119: Improve an existing lesson plan

**Best for:** Improving a lesson without starting again.

**Difficulty:** Advanced

**Copy and paste:**
```text
Audit the lesson below for alignment, sequencing, modelling, pupil practice, assessment, accessibility and timing. Keep what is already strong. Identify the two or three highest-value changes and then provide a revised lesson sequence incorporating only those changes. Do not rewrite the lesson unnecessarily and do not invent missing statutory requirements.

YEAR GROUP: [YEAR_GROUP]
SUBJECT: [SUBJECT]
OBJECTIVE: [OBJECTIVE]
LESSON:
[PASTE LESSON]
```

**Related prompts:** 020, 118, 121

## Commercial Prompt 120: Turn a resource into differentiated versions

**Best for:** Adapting an existing worksheet or activity for a mixed-attainment class.

**Difficulty:** Advanced

**Copy and paste:**
```text
Using the supplied resource, create three access versions while preserving the same core learning objective. Version A should provide appropriate scaffolding, Version B should retain the original level of independence, and Version C should add depth or reasoning rather than simply more questions. Keep the content accurate and identify exactly what has changed in each version.

YEAR GROUP: [YEAR_GROUP]
OBJECTIVE: [OBJECTIVE]
RESOURCE:
[PASTE RESOURCE]
```

**Related prompts:** 007, 071, 121

## Commercial Prompt 121: Turn a lesson into a pupil worksheet

**Best for:** Producing a printable pupil resource from an existing lesson.

**Difficulty:** Intermediate

**Copy and paste:**
```text
Turn the supplied lesson sequence into a pupil-facing worksheet for [YEAR_GROUP]. Include only the information pupils need, clear instructions, appropriate examples, practice tasks and a final reflection or check. Do not include teacher notes or answers in the pupil version. Then provide a separate teacher answer/checking section. Preserve the lesson objective and avoid unnecessary decoration.

LESSON:
[PASTE LESSON]
```

**Related prompts:** 015, 118, 120

## Commercial Prompt 122: Turn content into a quiz

**Best for:** Creating a quick knowledge or retrieval quiz from material you already teach.

**Difficulty:** Beginner

**Copy and paste:**
```text
Create a [NUMBER]-question quiz for [YEAR_GROUP] from the supplied teaching material. Prioritise important knowledge rather than minor details. Mix question formats where useful and provide a complete answer key. Keep wording age appropriate and unambiguous. Do not introduce facts that are not supported by the source material.

TEACHING MATERIAL:
[PASTE MATERIAL]
```

**Related prompts:** 052, 058, 123

## Commercial Prompt 123: Turn a lesson into retrieval questions

**Best for:** Reusing previous teaching for future retrieval practice.

**Difficulty:** Beginner

**Copy and paste:**
```text
Use the supplied lesson or notes to create [NUMBER] retrieval questions for future lessons. Prioritise essential knowledge, vocabulary and concepts pupils should retain. Provide concise answers. Mix the order of topics where useful and avoid questions that require information not contained in the source. Label any question that requires application rather than pure retrieval.

SOURCE:
[PASTE LESSON OR NOTES]
```

**Related prompts:** 004, 005, 122

## Commercial Prompt 124: Turn a model answer into teaching material

**Best for:** Making an existing example more useful for instruction.

**Difficulty:** Intermediate

**Copy and paste:**
```text
Analyse the supplied model answer for [YEAR_GROUP] [SUBJECT]. Turn it into a teaching resource showing the important features, teacher modelling points, vocabulary, common misconceptions and a short guided-practice task. Do not simply praise the answer. Make the learning visible so pupils can understand how to produce their own response.

MODEL ANSWER:
[PASTE MODEL]
OBJECTIVE:
[OBJECTIVE]
```

**Related prompts:** 011, 027, 068

## Commercial Prompt 125: Create classroom-ready examples from a topic

**Best for:** Generating examples that can be modelled or discussed immediately.

**Difficulty:** Intermediate

**Copy and paste:**
```text
Create [NUMBER] classroom-ready examples for [YEAR_GROUP] [SUBJECT] on [TOPIC]. Each example must serve a clear teaching purpose. Include a teacher note explaining what pupils should notice, one possible misconception and a question that tests understanding. Check all subject-specific facts, calculations, terminology and quotations where relevant.
```

**Related prompts:** 011, 032, 126

---

## Commercial Prompt 126: Repurpose a resource for another year group

**Best for:** Reusing good material without simply making it longer or shorter.

**Difficulty:** Advanced

**Copy and paste:**
```text
Adapt the supplied resource from [SOURCE_YEAR] to [TARGET_YEAR]. Preserve the underlying learning where appropriate, but adjust vocabulary, prerequisite knowledge, examples, scaffolding, expected independence and task demand for the target year group. Explain the major changes and identify anything that should not be carried across because it depends on the original curriculum sequence.

RESOURCE:
[PASTE RESOURCE]
```

**Related prompts:** 007, 071, 120

---

## Commercial Prompt 127: Turn a unit into a teacher-ready resource bank

**Best for:** Creating a reusable bank from an existing unit rather than starting from scratch next time.

**Difficulty:** Advanced

**Copy and paste:**
```text
Use the supplied unit plan to create a compact teacher resource bank containing retrieval questions, key vocabulary, worked examples, discussion questions, independent practice ideas, misconception checks and assessment questions. Do not create unnecessary duplicate resources. Organise everything by lesson or learning objective so it can be reused quickly.

UNIT PLAN:
[PASTE UNIT PLAN]
```

**Related prompts:** 003, 019, 122, 123
