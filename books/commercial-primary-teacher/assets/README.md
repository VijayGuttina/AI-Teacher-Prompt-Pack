# Commercial cover asset

The commercial edition build expects the approved customer-facing cover at:

`AI-Prompt-Toolkit-for-Primary-Teachers-cover.jpg`

Place the cover in this folder before running the commercial build.

The build process will:

- place the cover before the front matter in the assembled Markdown;
- force a page break after the cover;
- size the cover for the A4 publication layout;
- copy the same cover to `exports/covers/` for release packaging;
- include the cover in the generated DOCX and PDF builds.

This JPG is the customer-facing front cover. The KDP paperback edition will use a separate full wraparound cover built from the same visual design.
