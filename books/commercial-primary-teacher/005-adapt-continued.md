# Part 5: Adapt continued

## Commercial Prompt 079: Create sensory-friendly lesson adaptations

**Best for:** Reducing avoidable sensory barriers.

**Use when:** Noise, visual load, movement or materials may interfere with access.

**Difficulty:** Intermediate

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher planning an inclusive classroom environment.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Lesson: [LESSON]
Known sensory barrier: [BARRIER]
Available classroom options: [OPTIONS]

TASK
Identify practical environmental and task adaptations that reduce the stated barrier.

REQUIREMENTS
Keep the learning objective unchanged. Consider workspace, visual load, transitions, noise, equipment and predictable routines.

OUTPUT FORMAT
Barrier; adaptation; implementation; pupil choice; teacher check.

QUALITY CHECKS
Avoid assumptions about an individual pupil. Use known needs or agreed school information only.
```
**Related prompts:** 071, 076, 078

## Commercial Prompt 080: Create alternative response modes

**Best for:** Allowing pupils to demonstrate learning in different ways where appropriate.

**Use when:** Writing or speech is an incidental barrier to the intended construct.

**Difficulty:** Advanced

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher and assessment specialist.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Objective: [OBJECTIVE]
Original response mode: [MODE]
Observed barrier: [BARRIER]

TASK
Suggest alternative response modes that preserve the intended learning construct.

REQUIREMENTS
For each option explain what remains assessed and what incidental barrier is reduced. Consider oral, visual, practical, typed or structured responses where appropriate.

OUTPUT FORMAT
Alternative; construct preserved; barrier reduced; implementation; limitation.

QUALITY CHECKS
Do not change the response mode if the response mode itself is the construct being assessed.
```
**Related prompts:** 075, 076, 081

## Commercial Prompt 081: Create a scaffolded writing task

**Best for:** Supporting independent writing without writing the answer for pupils.

**Use when:** Pupils need help organising ideas, vocabulary or sentence structure.

**Difficulty:** Intermediate

**Copy and paste:**
```text
ROLE
Act as an experienced primary writing teacher specialising in adaptive teaching.

CONTEXT
Year group: [YEAR_GROUP]
Genre/task: [TASK]
Objective: [OBJECTIVE]
Success criteria: [CRITERIA]
Observed barrier: [BARRIER]

TASK
Create a scaffolded version of the writing task that pupils can gradually complete independently.

REQUIREMENTS
Include vocabulary support, planning prompts, sentence or paragraph structures and a fading plan. Do not generate the pupil's finished answer.

OUTPUT FORMAT
Scaffold; model; guided practice; independent step; fading point; self-check.

QUALITY CHECKS
The scaffold must support composition and decision-making rather than replace it.
```
**Related prompts:** 072, 077, 082

## Commercial Prompt 082: Create a fading-support plan

**Best for:** Preventing scaffolds from becoming permanent dependencies.

**Use when:** A pupil currently relies on support to complete a task.

**Difficulty:** Advanced

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher reviewing a support strategy.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Objective: [OBJECTIVE]
Current support: [SUPPORT]
Evidence of independence: [EVIDENCE]

TASK
Create a staged plan for reducing the support while maintaining successful access to learning.

REQUIREMENTS
Define what remains, what is reduced, what is removed and what evidence would justify each change.

OUTPUT FORMAT
Current support; stage 1; stage 2; stage 3; independence check.

QUALITY CHECKS
Do not remove support simply because a timetable says it should be removed. Use evidence.
```
**Related prompts:** 072, 081, 083

## Commercial Prompt 084: Create an inclusion check for a lesson

**Best for:** Reviewing whether a lesson is accessible before teaching it.

**Use when:** You want a quick inclusion audit rather than a complete rewrite.

**Difficulty:** Intermediate

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher reviewing lesson accessibility.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Objective: [OBJECTIVE]
Lesson plan: [LESSON]
Known class considerations: [CONSIDERATIONS]

TASK
Audit the lesson for avoidable access barriers and recommend only changes that materially improve participation.

OUTPUT FORMAT
Barrier; who may experience it; adaptation; learning demand preserved; priority.

QUALITY CHECKS
Avoid assumptions about pupils and do not recommend unnecessary individualisation.
```
**Related prompts:** 071, 079, 080

## Commercial Prompt 085: Create an accessible resource version

**Best for:** Adapting an existing worksheet or handout for access.

**Use when:** The content is appropriate but the format creates unnecessary barriers.

**Difficulty:** Intermediate

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher and accessible-resource designer.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Objective: [OBJECTIVE]
Existing resource: [RESOURCE]
Barrier to address: [BARRIER]

TASK
Create an accessible version while preserving the learning content and intended difficulty.

REQUIREMENTS
Consider layout, spacing, instructions, chunking, vocabulary, visual hierarchy and response space. Do not change the objective unless explicitly requested.

OUTPUT FORMAT
Accessibility issue; change; revised resource structure; teacher notes.

QUALITY CHECKS
Check that accessibility changes do not remove essential content or make the task materially easier.
```
**Related prompts:** 071, 073, 084

## Commercial Prompt 086: Plan inclusive participation in a whole-class lesson

**Best for:** Ensuring pupils have multiple realistic ways to participate.

**Use when:** A lesson relies heavily on hands-up questioning, extended writing or one response mode.

**Difficulty:** Intermediate

**Copy and paste:**
```text
ROLE
Act as an experienced primary teacher specialising in inclusive classroom participation.

CONTEXT
Year group: [YEAR_GROUP]
Subject: [SUBJECT]
Objective: [OBJECTIVE]
Lesson sequence: [SEQUENCE]
Known participation barriers: [BARRIERS]

TASK
Review the lesson and create a participation plan that gives pupils varied opportunities to think, rehearse and demonstrate learning.

REQUIREMENTS
Include individual thinking time, paired rehearsal, whole-class response methods and alternative response modes where appropriate. Keep the same learning objective.

OUTPUT FORMAT
Lesson point; participation method; purpose; access benefit; teacher check.

QUALITY CHECKS
Do not confuse participation with learning. Every method must support the intended learning.
```
**Related prompts:** 077, 080, 084
