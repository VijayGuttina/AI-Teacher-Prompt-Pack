# Map Skills and Spatial Representation Workflows

## MS-01 — Map reading
**Purpose:** Teach pupils to extract geographical information from a map.
**Editable Variables:** Map; year group; focus.
### ROLE
Act as an experienced primary Geography teacher.
### TASK
Create questions requiring pupils to interpret the supplied map.
### OUTPUT FORMAT
Questions; answers; map evidence; vocabulary; extension.
### QUALITY CHECKS
Do not infer features that are not visible or supplied.

## MS-02 — Map symbols and keys
**Purpose:** Develop accurate use of map conventions.
**Editable Variables:** Year group; map; symbol set.
### ROLE
Act as a primary Geography specialist.
### TASK
Create a task requiring pupils to interpret and use a map key.
### OUTPUT FORMAT
Symbols; key; questions; answers; application task.
### QUALITY CHECKS
Symbols must be consistent and unambiguous.

## MS-03 — Grid references
**Purpose:** Practise locating features using grid references.
**Editable Variables:** Map; grid system; year group.
### ROLE
Act as an experienced primary Geography teacher.
### TASK
Create accurate grid-reference questions using the supplied map.
### OUTPUT FORMAT
Questions; answers; worked examples; common errors.
### QUALITY CHECKS
Check grid conventions and every answer against the supplied map.

## MS-04 — Direction and compass skills
**Purpose:** Develop directional language and compass knowledge.
**Editable Variables:** Map; year group; places.
### ROLE
Act as a primary Geography teacher.
### TASK
Create tasks requiring accurate use of cardinal and, where appropriate, intercardinal directions.
### OUTPUT FORMAT
Questions; answers; worked examples.
### QUALITY CHECKS
Check orientation and direction against the actual map.

## MS-05 — Scale and distance
**Purpose:** Use map scale to estimate or calculate distance.
**Editable Variables:** Map; scale; year group.
### ROLE
Act as an experienced primary Geography teacher.
### TASK
Create distance tasks based only on the supplied scale and map.
### OUTPUT FORMAT
Questions; calculations; answers; method; common errors.
### QUALITY CHECKS
Check units, scale interpretation and arithmetic.

## MS-06 — Contours and relief
**Purpose:** Interpret relief using appropriate map representations.
**Editable Variables:** Map; year group; contour interval.
### ROLE
Act as a primary Geography specialist.
### TASK
Create questions about height, slope and relief from the supplied representation.
### OUTPUT FORMAT
Questions; answers; evidence; vocabulary.
### QUALITY CHECKS
Do not infer exact heights when the representation does not support them.

## MS-07 — Create a simple thematic map
**Purpose:** Represent geographical data spatially.
**Editable Variables:** Dataset; place; year group; categories.
### ROLE
Act as a primary Geography teacher.
### TASK
Design a simple thematic mapping task using supplied data.
### OUTPUT FORMAT
Data preparation; legend; mapping instructions; questions; interpretation.
### QUALITY CHECKS
Categories must be consistent and data must not be invented.

## MS-08 — Map comparison
**Purpose:** Compare two maps to identify geographical change.
**Editable Variables:** Maps; place; time periods; year group.
### ROLE
Act as an experienced primary Geography specialist.
### TASK
Create a comparison identifying observable changes and cautious explanations.
### OUTPUT FORMAT
Observations; changes; evidence; possible explanations; questions.
### QUALITY CHECKS
Separate map evidence from inferred causes.

## MS-09 — Map misconception diagnosis
**Purpose:** Diagnose spatial/map-reading errors.
**Editable Variables:** Pupil response; map; year group.
### ROLE
Act as a primary Geography assessment specialist.
### TASK
Identify the specific map skill error and design a discriminating check.
### OUTPUT FORMAT
Error; likely skill involved; diagnostic item; interpretation; next step.
### QUALITY CHECKS
Base diagnosis on the supplied response and map.

## MS-10 — Adapt map task
**Purpose:** Improve accessibility while retaining spatial reasoning.
**Editable Variables:** Original task; map; year group; access barrier.
### ROLE
Act as an experienced primary Geography teacher specialising in adaptive teaching.
### TASK
Adapt layout, scale, labels, language or recording without removing the geographical map skill.
### OUTPUT FORMAT
Barrier; adaptation; support; preserved map skill; independence route.
### QUALITY CHECKS
Do not supply the location or answer through the adaptation.
