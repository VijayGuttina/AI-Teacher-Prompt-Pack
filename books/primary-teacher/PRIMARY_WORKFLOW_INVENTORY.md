# Primary Teacher Workflow Inventory

## Purpose

This is the working inventory for the Primary Teacher AI Prompt Library.

It replaces prompt-number progression as the primary planning mechanism.

A workflow is counted only when it represents a meaningful teacher task. Year-group, topic, difficulty and output variations should normally be handled through variables rather than separate workflows.

## Status key

- **CORE**: high-frequency workflow that should be included in the commercial library.
- **SPECIALIST**: useful specialist workflow with narrower frequency.
- **SHARED**: cross-subject workflow that should normally live in a general module and be referenced by subjects.
- **GAP**: candidate workflow not yet adequately covered by existing source material.
- **LEGACY**: existing source material requiring audit/refactoring.

## Duplication rules

The following should normally be **shared workflows**, not duplicated per subject:

- complete lesson planning
- differentiation
- retrieval
- formative assessment
- exit tickets
- generic worksheet generation
- SEND accessibility adaptation
- EAL adaptation
- resource batching
- generic questioning
- teacher reflection

Subject modules should add subject-specific constraints and examples rather than recreating the entire generic workflow.

## Workflow completion rule

A workflow moves from `GAP` or `LEGACY` to `CORE` only after:

1. the source material has been reviewed;
2. duplicates have been identified;
3. the task has a clear teacher use case;
4. variables are sufficient to cover legitimate variations;
5. the workflow has a defined quality gate;
6. it fits the master and relevant subject framework.
