# Problem Solving and Reasoning Workflows

## PR-01 — Problem-solving lesson
**Purpose:** Plan a lesson that teaches pupils to solve a defined mathematical problem type.

### Editable Variables
- Year group
- Mathematical objective
- Problem type
- Prerequisites
- Lesson duration

### ROLE
Act as an experienced primary mathematics teacher specialising in problem solving.

### TASK
Design a sequence that makes the underlying mathematics explicit while requiring pupils to make decisions rather than follow a supplied procedure.

### REQUIREMENTS
Include teacher modelling, worked examples, guided reasoning, independent problems and reflection. Avoid making reading difficulty the main source of challenge.

### OUTPUT FORMAT
1. Objective
2. Prior knowledge
3. Problem structure
4. Modelled reasoning
5. Guided problems
6. Independent problems
7. Answers
8. Reflection

### QUALITY CHECKS
Verify every problem, answer and stated strategy.

## PR-02 — Bar modelling / visual representation
**Purpose:** Use a visual model to clarify a suitable word problem.

### Editable Variables
- Year group
- Problem
- Representation
- Known/unknown quantities

### ROLE
Act as a primary mathematics specialist.

### TASK
Analyse the supplied problem and propose a mathematically valid visual representation, explaining what each part represents.

### REQUIREMENTS
Do not force a bar model where another representation is clearer. Preserve the mathematical relationships in the problem.

### OUTPUT FORMAT
1. Mathematical structure
2. Recommended representation
3. Labelled model description
4. Equation or calculation
5. Pupil explanation prompt

### QUALITY CHECKS
Check that the representation matches the relationships in the problem.

## PR-03 — Multiple-solution problem
**Purpose:** Generate a problem with more than one valid solution or strategy.

### Editable Variables
- Year group
- Topic
- Number range
- Minimum solutions
- Difficulty

### ROLE
Act as an experienced primary problem-solving teacher.

### TASK
Create a mathematically valid open problem and provide multiple valid solutions or solution paths.

### REQUIREMENTS
Make the openness intentional. State constraints clearly enough for the problem to be assessable.

### OUTPUT FORMAT
1. Problem
2. Teacher notes
3. Possible solutions
4. Reasoning pathways
5. Extension

### QUALITY CHECKS
Confirm that every proposed solution satisfies every stated constraint.

## PR-04 — Always, sometimes, never
**Purpose:** Develop mathematical reasoning through classification of statements.

### Editable Variables
- Year group
- Mathematical topic
- Statements
- Difficulty

### ROLE
Act as a primary mathematics reasoning specialist.

### TASK
Create statements for pupils to classify as always, sometimes or never true, with justification requirements.

### REQUIREMENTS
Ensure each classification is mathematically defensible and include counterexamples where appropriate.

### OUTPUT FORMAT
1. Statements
2. Classification
3. Justification
4. Counterexample where relevant
5. Teacher discussion prompts

### QUALITY CHECKS
Test each statement against multiple valid cases before assigning its classification.

## PR-05 — Odd-one-out reasoning
**Purpose:** Create mathematical classification tasks with more than one defensible justification.

### Editable Variables
- Year group
- Topic
- Objects/numbers/statements
- Difficulty

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create an odd-one-out task where pupils must justify their choice and recognise alternative valid reasoning where appropriate.

### REQUIREMENTS
Avoid tasks where the intended answer depends on an unstated rule.

### OUTPUT FORMAT
1. Task
2. Likely answers
3. Valid justifications
4. Teacher prompts
5. Extension

### QUALITY CHECKS
Check that each proposed justification is mathematically valid.

## PR-06 — Spot the mistake
**Purpose:** Use an intentionally incorrect solution to develop mathematical reasoning.

### Editable Variables
- Year group
- Topic
- Incorrect solution
- Intended misconception

### ROLE
Act as a primary mathematics teacher.

### TASK
Create or analyse a plausible incorrect solution and ask pupils to identify, explain and correct the error.

### REQUIREMENTS
The error should be plausible, not absurd. Distinguish the observed error from any inferred misconception.

### OUTPUT FORMAT
1. Problem
2. Incorrect solution
3. Error location
4. Explanation
5. Correct solution
6. Follow-up question

### QUALITY CHECKS
Verify the original problem and corrected solution.

## PR-07 — Reasoning sentence stems
**Purpose:** Support mathematical explanation without scripting the mathematical thinking.

### Editable Variables
- Year group
- Topic
- Reasoning demand
- Language barrier

### ROLE
Act as an experienced primary mathematics teacher specialising in adaptive teaching.

### TASK
Create concise sentence stems that support pupils in explaining mathematical reasoning.

### REQUIREMENTS
Stems should support explanation, comparison, justification or evaluation without giving away the mathematical answer.

### OUTPUT FORMAT
1. Reasoning demand
2. Sentence stems
3. Example use
4. Teacher note

### QUALITY CHECKS
Ensure stems support thinking rather than substitute for it.

## PR-08 — Problem-solving misconception diagnosis
**Purpose:** Diagnose why a pupil is struggling with a supplied problem-solving task.

### Editable Variables
- Year group
- Pupil work
- Problem
- Recent teaching

### ROLE
Act as a primary mathematics diagnostic specialist.

### TASK
Analyse the evidence, distinguish observable behaviour from hypotheses, create diagnostic questions and recommend a targeted response.

### OUTPUT FORMAT
1. Observed behaviour
2. Plausible explanations
3. Evidence for/against each
4. Diagnostic question
5. Teaching response
6. Follow-up check

### QUALITY CHECKS
Do not infer a fixed ability level from a small evidence sample.

## PR-09 — Mixed-strategy problem set
**Purpose:** Create problems where pupils must decide which mathematical strategy is appropriate.

### Editable Variables
- Year group
- Topics
- Number range
- Difficulty

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a mixed problem set in which the strategy is not named in the question.

### REQUIREMENTS
Ensure each problem has sufficient information and a defensible solution. Include a strategy-justification prompt.

### OUTPUT FORMAT
1. Problems
2. Answers
3. Strategy used
4. Reasoning guidance
5. Common traps

### QUALITY CHECKS
Verify every calculation and ensure no problem unintentionally requires an out-of-scope method.

## PR-10 — Adapt a problem-solving task
**Purpose:** Increase access to a problem while preserving mathematical challenge.

### Editable Variables
- Original problem
- Year group
- Access barrier
- Objective
- Existing support

### ROLE
Act as an experienced primary mathematics teacher specialising in adaptive teaching.

### TASK
Adapt the problem to reduce the stated access barrier without removing the central mathematical decision or reasoning demand.

### REQUIREMENTS
Consider vocabulary, layout, representation, chunking and worked-example support. Do not assume a diagnosis.

### OUTPUT FORMAT
1. Original objective
2. Barrier
3. Adapted problem
4. Support
5. Independence route
6. Mathematical-demand check

### QUALITY CHECKS
Confirm that the pupil still has to solve the same underlying mathematical problem.
