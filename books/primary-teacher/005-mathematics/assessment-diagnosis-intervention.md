# Assessment, Diagnosis and Intervention Workflows

## ADI-01 — Mathematics exit ticket
**Purpose:** Create a short assessment aligned to a stated objective.

### Editable Variables
- Year group
- Objective
- Prerequisites
- Number of questions
- Difficulty

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a concise exit ticket that samples the intended mathematical understanding rather than merely repeating one question format.

### REQUIREMENTS
Include at least one item that reveals reasoning where appropriate. Provide a complete answer key and teacher interpretation guidance.

### OUTPUT FORMAT
1. Objective
2. Questions
3. Answers
4. What each item assesses
5. Interpretation guidance
6. Suggested next step

### QUALITY CHECKS
Verify every answer and ensure every item aligns to the objective.

## ADI-02 — Mathematics hinge question
**Purpose:** Create a diagnostic hinge question for use during teaching.

### Editable Variables
- Year group
- Objective
- Likely misconception
- Response options

### ROLE
Act as a primary mathematics assessment specialist.

### TASK
Create a hinge question with carefully designed distractors that distinguish likely understanding from specific misconceptions.

### REQUIREMENTS
Distractors must be mathematically plausible and diagnostically meaningful. Do not use obviously silly alternatives.

### OUTPUT FORMAT
1. Hinge question
2. Options
3. Correct answer
4. What each distractor may indicate
5. Teacher response

### QUALITY CHECKS
Verify that each distractor maps to a defensible mathematical error.

---

## ADI-03 — Curriculum objective assessment
**Purpose:** Build a short assessment against a stated primary mathematics objective.

### Editable Variables
- Year group
- Curriculum objective
- Coverage scope
- Number of items
- Difficulty range

### ROLE
Act as a primary mathematics assessment designer.

### TASK
Create a balanced assessment that samples the stated objective across varied representations and question structures.

### REQUIREMENTS
Separate procedural fluency from conceptual understanding where appropriate. Include an answer key and marking guidance.

### OUTPUT FORMAT
1. Assessment blueprint
2. Questions
3. Answers
4. Marking guidance
5. Interpretation bands
6. Follow-up actions

### QUALITY CHECKS
Check mathematical accuracy, coverage and fairness of each item.

---

## ADI-04 — Analyse pupil work
**Purpose:** Analyse supplied mathematics work to identify patterns for teaching.

### Editable Variables
- Year group
- Objective
- Pupil work
- Recent teaching
- Assessment context

### ROLE
Act as an experienced primary mathematics assessment and diagnostic specialist.

### CONTEXT
Treat any explanation of an error as a hypothesis unless directly established by evidence.

### TASK
Analyse the work for observable strengths, errors, patterns and plausible misconceptions, then recommend the smallest useful next teaching step.

### OUTPUT FORMAT
1. Strengths demonstrated
2. Observable errors
3. Pattern across responses
4. Plausible explanations
5. Evidence
6. Diagnostic check
7. Next teaching step
8. Follow-up assessment

### QUALITY CHECKS
Do not infer ability, effort or a fixed misconception from insufficient evidence.

---

## ADI-05 — Group pupils for targeted mathematics teaching
**Purpose:** Convert assessment evidence into flexible instructional groups.

### Editable Variables
- Pupil results
- Objectives
- Error patterns
- Available adult support
- Lesson duration

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create temporary, objective-specific teaching groups based only on the supplied evidence.

### REQUIREMENTS
Avoid labels suggesting fixed ability. State the evidence supporting each grouping and the teaching focus.

### OUTPUT FORMAT
1. Group
2. Evidence
3. Mathematical need
4. Teaching focus
5. Suggested activity
6. Success check
7. Exit/re-grouping criterion

### QUALITY CHECKS
Groups must be flexible and tied to specific learning needs.

---

## ADI-06 — Targeted intervention sequence
**Purpose:** Design a short intervention for a clearly evidenced mathematical gap.

### Editable Variables
- Year group
- Identified gap
- Evidence
- Prerequisites
- Sessions available

### ROLE
Act as an experienced primary mathematics intervention teacher.

### TASK
Design a focused sequence that addresses the identified gap through explanation, representation, guided practice and independent checking.

### REQUIREMENTS
Start from prerequisite knowledge. Include cumulative review and a final transfer check.

### OUTPUT FORMAT
1. Identified need
2. Prerequisites
3. Session sequence
4. Key representations
5. Practice
6. Diagnostic checks
7. Exit criterion

### QUALITY CHECKS
Do not design an intervention around an unverified diagnosis.

---

## ADI-07 — Intervention misconception check
**Purpose:** Test whether a suspected misconception is actually present.

### Editable Variables
- Year group
- Suspected misconception
- Evidence
- Mathematical topic

### ROLE
Act as a primary mathematics diagnostic specialist.

### TASK
Create a small set of discriminating questions that can distinguish the suspected misconception from alternative explanations.

### OUTPUT FORMAT
1. Hypothesis
2. Diagnostic questions
3. Expected responses
4. Interpretation
5. Follow-up teaching

### QUALITY CHECKS
Each question must provide useful evidence rather than simply repeat the original task.

---

## ADI-08 — Adaptive mathematics task
**Purpose:** Adapt a task for access while preserving the mathematical objective.

### Editable Variables
- Original task
- Objective
- Year group
- Access barrier
- Existing support

### ROLE
Act as an experienced primary mathematics teacher specialising in adaptive teaching.

### TASK
Adapt the supplied task without automatically lowering mathematical demand.

### REQUIREMENTS
Consider representation, language, layout, chunking, worked examples, manipulatives and response method. Explain what has changed and what has deliberately not changed.

### OUTPUT FORMAT
1. Original objective
2. Barrier
3. Adapted task
4. Support
5. Preserved demand
6. Independence route
7. Review point

### QUALITY CHECKS
Confirm that the same mathematical knowledge or reasoning remains the target.

## ADI-09 — Retrieval and re-teach planner
**Purpose:** Turn identified gaps into a short retrieval and re-teaching cycle.

### Editable Variables
- Year group
- Gap
- Prior learning
- Lesson sequence
- Review interval

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a retrieval-to-reteach cycle that revisits prerequisite knowledge, addresses the gap and checks later retention.

### OUTPUT FORMAT
1. Gap
2. Retrieval questions
3. Re-teaching point
4. Guided practice
5. Independent application
6. Delayed retrieval
7. Success criterion

### QUALITY CHECKS
Ensure retrieval items genuinely test prerequisite knowledge rather than unrelated facts.

---

## ADI-10 — Mathematics assessment summary for teacher
**Purpose:** Convert assessment evidence into a concise teaching summary.

### Editable Variables
- Assessment data
- Objective(s)
- Pupil/group information
- Recent teaching
- Next lesson constraints

### ROLE
Act as an experienced primary mathematics assessment lead.

### TASK
Summarise what the evidence shows, what it does not establish, and what the teacher should prioritise next.

### REQUIREMENTS
Avoid inflated claims and avoid ranking pupils unless explicitly required. Prioritise actionable mathematical information.

### OUTPUT FORMAT
1. Secure understanding
2. Developing understanding
3. Common errors
4. Evidence limitations
5. Priority teaching actions
6. Diagnostic follow-up
7. Suggested review date

### QUALITY CHECKS
Every recommendation must be traceable to supplied evidence.
