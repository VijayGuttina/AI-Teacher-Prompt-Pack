# Geometry and Measure Workflows

## GM-01 — Geometry concept lesson
**Purpose:** Teach a stated shape, property, position or geometric relationship.

### Editable Variables
- Year group
- Objective
- Shapes / concepts
- Prerequisites
- Lesson duration

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a conceptually clear geometry lesson matched to the stated objective.

### REQUIREMENTS
Use precise mathematical vocabulary, visual representations and examples/non-examples where useful. Include reasoning rather than identification alone.

### OUTPUT FORMAT
1. Objective
2. Prior knowledge
3. Representation
4. Teacher model
5. Guided practice
6. Reasoning questions
7. Independent check
8. Answers

### QUALITY CHECKS
Verify every geometric statement and classification.

## GM-09 — Geometry / measure misconception diagnosis
**Purpose:** Diagnose errors in geometry or measurement from supplied pupil work.

### Editable Variables
- Year group
- Pupil responses
- Objective
- Recent teaching

### ROLE
Act as a primary mathematics diagnostic specialist.

### TASK
Identify observable error patterns, propose plausible misconceptions, create diagnostic questions and recommend a targeted next step.

### REQUIREMENTS
Separate evidence from inference. Consider terminology, visual assumptions, unit confusion and concept confusion only where evidence supports them.

### OUTPUT FORMAT
1. Observed pattern
2. Possible explanation
3. Evidence
4. Diagnostic check
5. Teaching response
6. Follow-up

### QUALITY CHECKS
Do not present hypotheses as established facts.

## GM-10 — Adapt geometry / measure task
**Purpose:** Improve access to a geometry or measure task without reducing its intended mathematical demand.

### Editable Variables
- Original task
- Year group
- Mathematical objective
- Access barrier
- Existing support

### ROLE
Act as an experienced primary teacher specialising in adaptive mathematics teaching.

### TASK
Adapt the supplied task while preserving the mathematical objective and core reasoning demand.

### REQUIREMENTS
Consider visual clarity, language load, representation, number of items and response format. Do not assume a diagnosis.

### OUTPUT FORMAT
1. Objective
2. Barrier
3. Adapted task
4. Teacher support
5. Independence route
6. Mathematical-demand check

### QUALITY CHECKS
Confirm that the adaptation has not changed the mathematics being assessed.
