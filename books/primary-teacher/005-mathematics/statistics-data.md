# Statistics and Data Workflows

## SD-01 — Statistics lesson
**Purpose:** Plan a lesson around a stated statistics objective.

### Editable Variables
- Year group
- Objective
- Data set
- Representation
- Lesson duration

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a focused statistics lesson using an appropriate data context and representation.

### REQUIREMENTS
Include interpretation as well as construction or calculation. Keep the data set mathematically coherent and appropriate to the year group.

### OUTPUT FORMAT
1. Objective
2. Prior knowledge
3. Data set
4. Representation
5. Questions
6. Answers
7. Reasoning

### QUALITY CHECKS
Verify every data value, calculation and conclusion.

## SD-06 — Interpret misleading or incomplete data
**Purpose:** Develop critical interpretation of data presentation.

### Editable Variables
- Year group
- Data representation
- Issue to expose
- Context

### ROLE
Act as a primary mathematics reasoning teacher.

### TASK
Create a data representation that contains a deliberate but age-appropriate interpretive issue, then generate questions that require pupils to identify and explain it.

### REQUIREMENTS
The issue must be mathematically defensible and clearly explained in teacher notes.

### OUTPUT FORMAT
1. Representation
2. Task
3. Expected observation
4. Explanation
5. Extension

### QUALITY CHECKS
Ensure the intended issue is genuinely present and not caused by a calculation error.

## SD-08 — Statistics misconception diagnosis
**Purpose:** Diagnose errors in data handling or interpretation.

### Editable Variables
- Year group
- Pupil work
- Data set
- Objective

### ROLE
Act as a primary mathematics diagnostic specialist.

### TASK
Analyse the supplied work, identify observable errors, propose plausible misconceptions and design a diagnostic check.

### OUTPUT FORMAT
1. Observed error
2. Possible explanation
3. Evidence
4. Diagnostic question
5. Teaching response
6. Follow-up

### QUALITY CHECKS
Separate evidence from inference and verify the underlying data.

## SD-09 — Data reasoning problems
**Purpose:** Generate problems requiring pupils to reason from supplied data.

### Editable Variables
- Year group
- Data set
- Representation
- Difficulty

### ROLE
Act as an experienced primary problem-solving teacher.

### TASK
Create questions requiring comparison, interpretation, justification or prediction from a coherent data set.

### REQUIREMENTS
Avoid questions answerable by reading a single displayed value when deeper reasoning is intended.

### OUTPUT FORMAT
1. Data
2. Questions
3. Answers
4. Reasoning guidance
5. Extension

### QUALITY CHECKS
Verify every answer against the source data.

## SD-10 — Adapt statistics task
**Purpose:** Make a data task more accessible while preserving mathematical interpretation.

### Editable Variables
- Original task
- Year group
- Access barrier
- Objective

### ROLE
Act as an experienced primary teacher specialising in adaptive mathematics teaching.

### TASK
Adapt the supplied statistics task while preserving the intended mathematical interpretation and reasoning.

### REQUIREMENTS
Consider layout, visual clarity, vocabulary, data volume and response format without changing the underlying mathematics.

### OUTPUT FORMAT
1. Objective
2. Barrier
3. Adapted task
4. Support
5. Independence route
6. Mathematical-demand check

### QUALITY CHECKS
Confirm that the same statistical relationship remains under consideration.
