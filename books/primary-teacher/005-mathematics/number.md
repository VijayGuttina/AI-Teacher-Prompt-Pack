## NM-01 — Number and Place-Value Lesson Sequence

**Prompt Difficulty:** Advanced  
**AI Model Compatibility:** ChatGPT, Claude, Gemini, Copilot  
**Expected Output Length:** 700–1,000 words  
**Curriculum Tags:** KS1, KS2, Number, Place Value, Lesson Planning

### Editable Variables
`[YEAR_GROUP]` | `[OBJECTIVE]` | `[NUMBER_RANGE]` | `[PRIOR_KNOWLEDGE]` | `[DURATION]` | `[AVAILABLE_REPRESENTATIONS]`

### ROLE
Act as an experienced primary mathematics teacher and curriculum specialist with strong subject knowledge of number and place value.

### CONTEXT
Teach `[OBJECTIVE]` to `[YEAR_GROUP]` pupils within `[DURATION]`. Work within `[NUMBER_RANGE]`, build on `[PRIOR_KNOWLEDGE]`, and use `[AVAILABLE_REPRESENTATIONS]` where mathematically useful.

### TASK
Create a coherent lesson sequence moving from prerequisite retrieval through explicit modelling, guided practice, independent application and a short formative assessment check.

### REQUIREMENTS
Use precise mathematical language. Make the structure of the mathematics visible rather than relying on procedural rules alone. Include purposeful variation, likely misconceptions and teacher questions that reveal understanding. Do not use representations decoratively.

### OUTPUT FORMAT
Learning objective; prerequisites; key mathematical idea; lesson sequence; worked examples; guided practice; independent practice; misconceptions; formative assessment; answers and checks.

### QUALITY CHECKS
Verify every number, example, calculation and representation. Ensure the assessment aligns directly with the stated objective.

### OPTIONAL CUSTOMISATION
Adapt for KS1 or KS2, shorter lessons, intervention groups or whole-class teaching.

### Example Input
Year 4; objective: recognise the value of each digit in four-digit numbers; range: 1,000–9,999; prior knowledge: three-digit place value; duration: 60 minutes; base-ten equipment and place-value charts available.

### Example Output
Model the same number through concrete equipment, a place-value chart and expanded notation, then vary one digit at a time so pupils reason about which value changes and why.

## NM-03 — Place-Value Misconception Diagnosis

**Prompt Difficulty:** Advanced  
**AI Model Compatibility:** ChatGPT, Claude, Gemini, Copilot  
**Expected Output Length:** 500–800 words  
**Curriculum Tags:** KS1, KS2, Place Value, Misconceptions, Diagnosis

### Editable Variables
`[YEAR_GROUP]` | `[OBJECTIVE]` | `[PUPIL_RESPONSES]` | `[CORRECT_EXAMPLES]` | `[PRIOR_TEACHING]`

### ROLE
Act as a primary mathematics assessment specialist diagnosing mathematical thinking from evidence.

### CONTEXT
Pupils in `[YEAR_GROUP]` are learning `[OBJECTIVE]`. Their responses are `[PUPIL_RESPONSES]`; correct examples include `[CORRECT_EXAMPLES]`; relevant prior teaching is `[PRIOR_TEACHING]`.

### TASK
Separate observable error patterns from plausible explanations and design a short diagnostic check that distinguishes between competing hypotheses.

### REQUIREMENTS
Do not label a misconception as fact without sufficient evidence. Consider calculation slips, language interpretation, representation confusion and insecure prerequisite knowledge as alternatives.

### OUTPUT FORMAT
Observed evidence; possible explanations; confidence; discriminating diagnostic task; expected response patterns; targeted teaching response; reassessment.

### QUALITY CHECKS
The diagnostic task must genuinely distinguish hypotheses rather than repeat the original question.

### OPTIONAL CUSTOMISATION
Adapt for individual conferencing, small-group intervention or whole-class diagnosis.

### Example Input
Year 4; objective: compare four-digit numbers; pupil says 3,999 is greater than 4,001 because 999 is greater than 001.

### Example Output
Identify the observable comparison error, test whether the pupil attends first to the thousands digit and use a place-value comparison task before deciding the exact teaching response.

### TASK
