# Number and Place Value Workflows

## NM-01 — Number and place-value lesson sequence

**Purpose:** Plan an explicit lesson around a stated number or place-value objective.

**Editable Variables:** Year group; objective; number range; prior knowledge; duration.

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a concise lesson sequence that moves from prerequisite retrieval to explicit modelling, guided practice and independent application.

### REQUIREMENTS
Use precise mathematical language, representations where useful, purposeful variation and a short assessment check.

### OUTPUT FORMAT
Objective; prerequisites; model; guided practice; independent task; assessment; misconceptions.

### QUALITY CHECKS
Verify every mathematical example and answer.

---

## NM-02 — Place-value representation builder

**Purpose:** Generate linked concrete, pictorial and abstract representations for a number concept.

**Editable Variables:** Year group; numbers; representation available; objective.

### ROLE
Act as a primary mathematics specialist.

### TASK
Create representations that make the place-value structure visible and connect them explicitly.

### REQUIREMENTS
Do not use representations merely decoratively. Explain what each representation makes visible.

### OUTPUT FORMAT
1. Concrete representation
2. Pictorial representation
3. Abstract notation
4. Teacher questions
5. Common misconception

### QUALITY CHECKS
Representations and notation must describe the same mathematics.

---

## NM-03 — Place-value misconception diagnosis

**Purpose:** Analyse pupil responses and identify plausible place-value misconceptions.

**Editable Variables:** Year group; objective; pupil responses; correct examples.

### ROLE
Act as a primary mathematics assessment specialist.

### TASK
Separate observed error patterns from possible explanations and design a diagnostic check.

### OUTPUT FORMAT
Observed pattern; possible explanation; evidence; diagnostic question/task; teaching response; follow-up.

### QUALITY CHECKS
Do not claim a misconception as fact without supporting evidence.

---

## NM-04 — Number comparison and ordering

**Purpose:** Create graduated comparison and ordering tasks.

**Editable Variables:** Year group; number range; number type; difficulty; number of items.

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create a sequence that develops comparison and ordering while varying the mathematical structure deliberately.

### REQUIREMENTS
Include reasoning prompts such as "How do you know?" where appropriate.

### OUTPUT FORMAT
Practice sequence; reasoning prompts; answers.

### QUALITY CHECKS
Check all orderings and identify any ties or equivalent values.

## NM-05 — Number-line reasoning

**Purpose:** Use number lines to develop magnitude, position and interval reasoning.

**Editable Variables:** Year group; range; scale; objective; number of tasks.

### ROLE
Act as a primary mathematics specialist.

### TASK
Create number-line tasks that require pupils to reason about position, distance or intervals rather than simply read labels.

### OUTPUT FORMAT
1. Setup
2. Tasks
3. Reasoning prompts
4. Answers
5. Misconceptions

### QUALITY CHECKS
Check scale consistency and interval calculations.

## NM-06 — Number sense fluency set

**Purpose:** Create short number-sense practice focused on structure and relationships.

**Editable Variables:** Year group; number range; skill; number of items.

### ROLE
Act as an experienced primary mathematics teacher.

### TASK
Create varied number-sense questions that reveal relationships and mental strategies.

### REQUIREMENTS
Avoid generating many cosmetic variations of the same calculation.

### OUTPUT FORMAT
Questions; expected strategy; answers; extension.

### QUALITY CHECKS
Check that each item tests the intended number relationship.

---

## NM-07 — Number pattern and sequence reasoning

**Purpose:** Develop reasoning about numerical patterns and rules.

**Editable Variables:** Year group; starting values; rule type; number of terms.

### ROLE
Act as a primary mathematics teacher specialising in mathematical reasoning.

### TASK
Create pattern tasks requiring pupils to identify, explain, extend or challenge a rule.

### OUTPUT FORMAT
Pattern; questions; reasoning prompts; answers; challenge.

### QUALITY CHECKS
The stated rule must generate every supplied term.

---

## NM-08 — Adapt number task

**Purpose:** Adapt a number task for an identified access barrier without unnecessarily reducing mathematical demand.

**Editable Variables:** Original task; year group; objective; access barrier; existing support.

### ROLE
Act as an experienced primary mathematics teacher specialising in adaptive teaching.

### TASK
Adapt the task while preserving its intended mathematical thinking.

### OUTPUT FORMAT
Barrier; adaptation; teacher guidance; independence-release option.

### QUALITY CHECKS
Do not equate adaptation with simply making the numbers easier.

---

## NM-09 — Number reasoning challenge

**Purpose:** Create a deeper reasoning task from a core number objective.

**Editable Variables:** Year group; core objective; number range; starting task.

### ROLE
Act as a primary mathematics reasoning specialist.

### TASK
Create a task that increases mathematical depth through justification, comparison, generalisation or proof-like reasoning rather than merely larger numbers.

### OUTPUT FORMAT
Core task; reasoning challenge; teacher prompts; expected reasoning; answers.

### QUALITY CHECKS
Challenge must remain mathematically accessible at the stated year-group level.

---

## NM-10 — Number assessment exit ticket

**Purpose:** Create a short formative check aligned to a number objective.

**Editable Variables:** Year group; objective; prerequisites; number of questions.

### ROLE
Act as a primary mathematics assessment specialist.

### TASK
Create a concise exit ticket that distinguishes procedural success from conceptual understanding where possible.

### OUTPUT FORMAT
Questions; answers; interpretation guide; next-step options.

### QUALITY CHECKS
Each item must test the stated objective and have an unambiguous answer unless ambiguity is intentional.
