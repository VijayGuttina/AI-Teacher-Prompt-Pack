# MFL Family 4: Vocabulary, Retrieval & Language Chunks

This family contains 10 copy/paste-ready workflows for selecting, teaching, retrieving, assessing and adapting primary MFL vocabulary and high-frequency language chunks.

## Family principles

- Prioritise high-frequency, useful and curriculum-relevant vocabulary over arbitrary word lists.
- Teach vocabulary in meaningful context and reuse it cumulatively.
- Treat language chunks as usable units of meaning, not merely strings to memorise.
- Distinguish recognition, recall, pronunciation, meaning, controlled use, independent use and transfer.
- Use spaced, varied and appropriately low-stakes retrieval.
- Avoid excessive novelty and cognitive overload.
- Do not treat copying as evidence of vocabulary knowledge.
- Do not invent target-language vocabulary, meanings, grammatical forms, pronunciation claims or authentic source material.
- If the target language is unspecified, use `[TARGET LANGUAGE]` and identify language-specific items that require verification.
- Mark uncertain language-specific forms with `[VERIFY]` rather than presenting them as authoritative.
- Include pronunciation and phonics support when it is relevant to successful vocabulary use.
- Keep grammar embedded appropriately, while maintaining vocabulary and chunk learning as the primary construct.
- Adapt access without changing the intended vocabulary construct.
- Avoid cultural stereotypes and do not imply that one vocabulary choice represents an entire country, community or culture.
- Use current reliable sources for claims that genuinely depend on current information.
- Never invent school procedures, local syllabus requirements or safeguarding arrangements.
- Assess observable language knowledge and use, not confidence, personality or willingness to perform.

## VR-01: Select High-Value Vocabulary for a Primary MFL Unit

**Prompt ID:** VR-01  
**Difficulty:** Intermediate  
**AI Model Compatibility:** ChatGPT, Claude, Gemini, Copilot  
**Expected Output Length:** 800–1,200 words  
**Typical Generation Time:** 1–2 minutes  
**Curriculum Tags:** MFL, vocabulary, curriculum planning, primary, retrieval, language chunks, progression

### ROLE

Act as an experienced primary MFL curriculum designer with expertise in vocabulary acquisition, cumulative language progression, retrieval practice and age-appropriate language teaching.

### CONTEXT

I am planning a primary MFL unit and need to select vocabulary that pupils genuinely need in order to understand and communicate about the unit content.

Use these editable variables:

| Variable | Value |
|---|---|
| Target language | [TARGET LANGUAGE] |
| Year group | [YEAR GROUP] |
| Unit/topic | [UNIT TOPIC] |
| Curriculum objective | [CURRICULUM OBJECTIVE] |
| Existing vocabulary pupils know | [KNOWN VOCABULARY] |
| Unit length | [NUMBER OF LESSONS] |
| School vocabulary priorities | [SCHOOL PRIORITIES OR NONE SUPPLIED] |

### TASK

Select a high-value vocabulary set for the unit. Prioritise words and language chunks that are frequent, useful, transferable, necessary for the curriculum objective, and suitable for repeated use across lessons.

### REQUIREMENTS

1. Separate vocabulary into:
   - essential core vocabulary
   - high-value supporting vocabulary
   - useful language chunks
   - optional extension vocabulary
2. Explain why each item belongs in its category.
3. Identify opportunities for cumulative reuse.
4. Include recognition, recall and communicative-use expectations.
5. Identify pronunciation or phonics considerations where relevant.
6. Avoid introducing vocabulary simply because it is associated with the topic if it has low instructional value.
7. Do not invent target-language forms. If language-specific knowledge cannot be verified, use `[VERIFY]`.
8. Do not assume French, Spanish or another particular language unless supplied.
9. Flag words whose register, gender, plurality, agreement, conjugation or usage requires language-specific verification.
10. Recommend a manageable number of new items for the stated year group and lesson sequence.

### OUTPUT FORMAT

Provide:
1. Unit vocabulary rationale
2. Essential vocabulary table: English meaning, target-language form, function, pronunciation/phonics note, verification status
3. High-value supporting vocabulary
4. High-frequency chunks
5. Extension vocabulary
6. Cumulative reuse opportunities
7. Recommended introduction sequence
8. Retrieval priorities
9. Teacher implementation notes
10. Verification items

### QUALITY CHECKS

Before finalising, check that the selection is manageable, curriculum-relevant, cumulative, language-accurate, communicatively useful and not simply a long topic word list.

### OPTIONAL CUSTOMISATION

If `[KNOWN VOCABULARY]` is supplied, explicitly identify which items should be retrieved rather than retaught. If no school-specific priorities are supplied, state that clearly rather than inventing them.

**Typical Generation Time:** 1–2 minutes  
**Curriculum Tags:** MFL, retrieval practice, vocabulary, sequencing, primary, spaced learning

### ROLE

Act as a primary MFL retrieval-practice specialist who designs cumulative vocabulary sequences that move pupils from initial exposure towards secure recall and communicative use.

### CONTEXT

Create a retrieval-rich sequence for:

| Variable | Value |
|---|---|
| Target language | [TARGET LANGUAGE] |
| Year group | [YEAR GROUP] |
| Unit/topic | [UNIT TOPIC] |
| New vocabulary | [NEW VOCABULARY OR VOCABULARY SET] |
| Previously taught vocabulary | [PREVIOUS VOCABULARY] |
| Number of lessons | [NUMBER OF LESSONS] |
| Typical lesson length | [LESSON LENGTH] |

### TASK

Build a lesson-by-lesson retrieval sequence showing when vocabulary is first introduced, revisited, varied, combined and transferred.

### REQUIREMENTS

1. Use a mixture of retrieval types, including recognition, recall, discrimination, meaning matching, oral recall, sentence completion and communicative use.
2. Space retrieval rather than repeating the same item immediately in identical form.
3. Interleave older vocabulary with new vocabulary where appropriate.
4. Control novelty so that pupils have sufficient opportunity to consolidate.
5. Distinguish retrieval from re-exposure.
6. Include increasingly demanding retrieval from supported recognition to independent recall and use.
7. Include pronunciation and phonics retrieval where relevant.
8. Use only verified target-language forms or `[VERIFY]` markers.
9. Do not use copying as the main evidence of recall.
10. Include teacher prompts and expected pupil actions.

6. End-of-lesson checks
7. Delayed retrieval schedule
8. Transfer tasks
9. Teacher monitoring points
10. Adaptations for pupils who need additional retrieval support

### QUALITY CHECKS

Check that retrieval is spaced, varied, cumulative and progressively demanding, and that activities measure actual recall rather than recognition or copying alone.

### OPTIONAL CUSTOMISATION

If lesson frequency is irregular, redesign the schedule around actual teaching dates rather than inventing a timetable.

Act as a primary MFL assessment and intervention specialist with expertise in diagnosing vocabulary knowledge accurately.

### CONTEXT
