## MC-01 — Materials Properties Lesson

**Prompt Difficulty:** Advanced  
**AI Model Compatibility:** ChatGPT, Claude, Gemini, Copilot  
**Expected Output Length:** 700–1,000 words  
**Curriculum Tags:** KS1, KS2, Science, Chemistry, Materials, Properties, Lesson Planning

### Editable Variables
`[YEAR_GROUP]` | `[OBJECTIVE]` | `[MATERIALS]` | `[PROPERTIES]` | `[CONTEXT]` | `[DURATION]`

### ROLE
Act as an experienced primary science teacher with secure subject knowledge of materials and their observable properties.

### CONTEXT
Teach `[OBJECTIVE]` to `[YEAR_GROUP]` pupils using `[MATERIALS]` in `[CONTEXT]` within `[DURATION]`.

### TASK
Design a lesson that moves from observation and vocabulary to comparison, explanation and application, linking material properties to suitable uses.

### REQUIREMENTS
Use precise property language. Distinguish observations from explanations about composition. Include retrieval, teacher modelling, guided comparison, independent reasoning and formative assessment. Do not treat a material's common use as proof of its properties.

### OUTPUT FORMAT
Objective; prior knowledge; vocabulary; observation activity; modelled explanation; comparison task; application task; questions; answers; misconception; assessment.

### QUALITY CHECKS
Verify every stated property and ensure examples are scientifically defensible. Keep the content appropriate to the year group and flag any simplification that could create a misconception.

### OPTIONAL CUSTOMISATION
Adapt for KS1 materials, KS2 properties, natural/man-made materials, or a practical lesson.

### Example Input
Year 2; objective: compare materials using observable properties; materials: wood, plastic, metal, fabric; context: choosing materials for classroom objects; 45 minutes.

### Example Output
Have pupils observe and compare properties such as hardness, flexibility, transparency and waterproofness, then justify which material is suitable for a specified object and why.

### CONTEXT
Teach `[OBJECTIVE]` to `[YEAR_GROUP]` pupils using `[EXAMPLES]` and `[REPRESENTATIONS]` at `[DIFFICULTY]` level.

### TASK
Develop a concept sequence connecting observable behaviour of solids, liquids and gases with an age-appropriate scientific model.

### Example Output
Use observable properties first, then introduce a simple particle model to explain differences in arrangement and movement without suggesting that the diagram is a photograph of matter.

### ROLE
Act as a primary chemistry specialist designing evidence-based classification tasks.

### CONTEXT
Create a task for `[YEAR_GROUP]` using `[EXAMPLES]` to address `[OBJECTIVE]`, with `[EVIDENCE_AVAILABLE]` available where relevant.

### TASK
Require pupils to classify changes and justify their decisions using observable evidence and curriculum-appropriate scientific reasoning.

### REQUIREMENTS
Distinguish reversible changes from changes that produce new substances. Where an example depends on conditions, state the conditions rather than presenting an absolute claim. Include borderline or discussion cases only when scientifically defensible.

### OUTPUT FORMAT

### Example Output
Classify the examples with explicit reasoning and make clear that dissolving and changes of state can be reversed under suitable conditions, whereas burning paper creates new substances.

## MC-09 — Materials Misconception Diagnosis

**Prompt Difficulty:** Advanced  
**AI Model Compatibility:** ChatGPT, Claude, Gemini, Copilot  
**Expected Output Length:** 600–900 words  
**Curriculum Tags:** KS1, KS2, Science, Materials, Misconceptions, Diagnostic Assessment

### Editable Variables
`[YEAR_GROUP]` | `[PUPIL_RESPONSES]` | `[OBJECTIVE]` | `[RECENT_TEACHING]`

### ROLE
Act as a primary science diagnostic specialist.

### CONTEXT
Analyse `[PUPIL_RESPONSES]` from `[YEAR_GROUP]` pupils working on `[OBJECTIVE]`, considering `[RECENT_TEACHING]`.

### TASK
Identify observable errors, distinguish plausible explanations and design diagnostic tasks that reveal the most useful next teaching step.

### REQUIREMENTS
Consider vocabulary, observation, classification, particle models, changes of state, dissolving and causal reasoning as distinct possibilities where relevant. Separate evidence from inference and do not infer fixed ability from a limited response.

### OUTPUT FORMAT
Observed error; plausible hypotheses; evidence; discriminating question; expected response patterns; teaching response; follow-up assessment.

### QUALITY CHECKS
Each diagnostic task must distinguish between at least two plausible explanations rather than simply repeat the original question. Verify all science content.

### OPTIONAL CUSTOMISATION
Adapt for individual conferencing, small-group intervention or whole-class formative assessment.

### Example Input
Year 5; response: “Salt disappears when it dissolves”; objective: explain dissolving; recent teaching: solutions and separation.

### Example Output
Use a recovery or evaporation demonstration and ask pupils to predict and explain what happens to the salt, testing whether they understand conservation of material rather than merely recalling the word “dissolve”.

### ROLE
Act as an experienced primary science teacher specialising in adaptive teaching and inclusive practical science.

### CONTEXT
Adapt `[ORIGINAL_TASK]` for `[YEAR_GROUP]`. The intended science objective is `[OBJECTIVE]`; the access barrier is `[ACCESS_BARRIER]`; existing support is `[EXISTING_SUPPORT]`.

### TASK
Reduce unnecessary language, visual, motor, sensory or procedural barriers while preserving the scientific question, evidence and thinking demand.

### REQUIREMENTS
Consider vocabulary, layout, chunking, equipment access, response format, demonstrations, visual supports and optional scaffolds. Do not assume a diagnosis. Do not remove the observation, comparison or reasoning that provides the evidence for the scientific objective.

### OUTPUT FORMAT
Original objective; barrier analysis; adapted task; equipment/support; teacher prompts; preserved scientific demand; independence route; assessment evidence; review point.

### QUALITY CHECKS

### OPTIONAL CUSTOMISATION
Adapt for SEND, EAL, working-memory, language, motor or sensory access needs.

### Example Input
Year 4; original task: investigate which material is most waterproof; barrier: dense written instructions; objective: compare material properties through a controlled test; existing support: visual timetable.

### Example Output
Retain the same materials, test and evidence requirements while presenting the procedure as numbered visual steps, pre-teaching key vocabulary and allowing oral explanation of the conclusion where writing is the access barrier.
