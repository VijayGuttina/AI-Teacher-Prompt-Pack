# About This Book

This book is a curated commercial edition of a larger AI prompt library developed specifically for primary teachers.

The aim is simple: give teachers practical prompts they can copy, adapt and use immediately for the work they already do.

The prompts cover planning, teaching, assessment, adaptation, subject-specific teaching and everyday time-saving tasks.

The focus is not on producing the largest possible collection of prompts. The focus is on producing prompts that are genuinely useful, clearly structured and capable of producing a strong first-pass result.

# How to Use This Book

## 1. Choose the task

Start with the problem you need to solve rather than looking for the most impressive prompt.

If you need a lesson, go to **Plan**. If you need a classroom activity, go to **Teach**. If you need evidence of learning, go to **Assess**. If you need to adapt an activity, go to **Adapt**.

## 2. Replace the variables

Most prompts contain clearly marked variables such as:

`[YEAR GROUP]`

`[SUBJECT]`

`[TOPIC]`

`[LEARNING OBJECTIVE]`

Replace these with your own information before submitting the prompt.

## 3. Give ChatGPT enough context

The quality of the result depends heavily on the quality of the context you provide.

Where relevant, include:

- Year group
- Subject
- Topic
- Learning objective
- Prior knowledge
- Lesson length
- Curriculum expectation
- Known barriers to learning
- Available resources
- Desired output

Do not provide confidential pupil information.

## 4. Review before use

Treat the first output as a professionally useful draft, not an unquestionable answer.

Check:

- Accuracy
- Curriculum alignment
- Age appropriateness
- Accessibility
- Vocabulary
- Examples
- Assessment validity
- Cultural accuracy
- Current information
- School-specific requirements

## 5. Use teacher judgement

You know your pupils, classroom and school better than the AI system does.

Use the output to reduce preparation time and generate ideas, then apply your own professional judgement before using it.

# Quick Start

If you are new to using ChatGPT as a teacher, start with these five tasks:

1. Create a lesson plan from a learning objective.
2. Generate questions to check understanding.
3. Create a differentiated classroom activity.
4. Build a short retrieval or knowledge check.
5. Turn an existing resource into a more accessible version.

These five workflows demonstrate the core value of the toolkit: **less preparation time, better starting points and more options for adapting teaching.**

---

# Responsible Use

Use AI to support professional work, not to outsource professional responsibility.

In particular:

- Never use AI to make safeguarding decisions.
- Never ask AI to diagnose a pupil.
- Never assume an AI-generated claim is accurate because it sounds confident.
- Never disclose sensitive pupil information unnecessarily.
- Never use generated assessment judgements as a substitute for professional assessment.
- Never assume generated information about a religion, culture, historical event, language or community is accurate without checking where accuracy matters.

When the information is uncertain, verify it.
