# Computing Vocabulary, Explanation & Misconceptions Workflows

**IDs:** VE-01 to VE-10

## VE-01 — Build a Computing Vocabulary Set
**ROLE:** Primary computing teacher. **CONTEXT:** Topic and year group supplied. **TASK:** Select essential vocabulary. **REQUIREMENTS:** Define terms precisely and distinguish commonly confused concepts. **OUTPUT FORMAT:** Vocabulary table with examples and non-examples. **QUALITY CHECKS:** Technical accuracy. **OPTIONAL CUSTOMISATION:** KS1/KS2.

## VE-02 — Explain a Computing Concept Simply
**ROLE:** Computing teacher. **CONTEXT:** Concept and age group supplied. **TASK:** Explain it without sacrificing accuracy. **REQUIREMENTS:** Avoid misleading analogies or label them as analogies. **OUTPUT FORMAT:** Explanation, example, check question. **QUALITY CHECKS:** Accuracy and age fit. **OPTIONAL CUSTOMISATION:** Analogy allowed.

## VE-03 — Generate Conceptual Examples and Non-Examples
**ROLE:** Computing teacher. **CONTEXT:** Concept supplied. **TASK:** Create examples and non-examples. **REQUIREMENTS:** Ensure each item genuinely discriminates the concept. **OUTPUT FORMAT:** Two-column table with rationale. **QUALITY CHECKS:** Conceptual validity. **OPTIONAL CUSTOMISATION:** Pupil sorting task.

## VE-04 — Diagnose Vocabulary Misuse
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil response supplied. **TASK:** Identify terminology misuse and underlying concept where evidence permits. **REQUIREMENTS:** Do not equate spelling errors with conceptual errors. **OUTPUT FORMAT:** Evidence, diagnosis, check, intervention. **QUALITY CHECKS:** Evidence discipline. **OPTIONAL CUSTOMISATION:** EAL/SEND.

## VE-05 — Create a Computing Explanation Scaffold
**ROLE:** Primary computing teacher. **CONTEXT:** Topic and expected explanation supplied. **TASK:** Build a scaffold for a precise pupil explanation. **REQUIREMENTS:** Include causal/functional links where appropriate. **OUTPUT FORMAT:** Sentence stems, vocabulary and success criteria. **QUALITY CHECKS:** Construct alignment. **OPTIONAL CUSTOMISATION:** Writing level.

## VE-06 — Improve a Pupil Explanation
**ROLE:** Computing teacher. **CONTEXT:** Pupil explanation supplied. **TASK:** Improve technical precision while preserving pupil voice. **REQUIREMENTS:** Identify conceptual changes separately from language edits. **OUTPUT FORMAT:** Original issue, improved version, teaching note. **QUALITY CHECKS:** Technical fidelity. **OPTIONAL CUSTOMISATION:** Minimal-edit mode.

## VE-07 — Create Hinge Questions for a Concept
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Concept and likely misconceptions supplied. **TASK:** Create a discriminating hinge question. **REQUIREMENTS:** Options must map to plausible misconceptions, not trivia. **OUTPUT FORMAT:** Question, options, misconception map, response pathway. **QUALITY CHECKS:** Diagnostic power. **OPTIONAL CUSTOMISATION:** Whole-class use.

## VE-08 — Adapt Technical Language for Learners
**ROLE:** Inclusive computing teacher. **CONTEXT:** Concept and learner need supplied. **TASK:** Make terminology accessible without changing its meaning. **REQUIREMENTS:** Keep canonical technical term visible. **OUTPUT FORMAT:** Term, accessible explanation, example, check. **QUALITY CHECKS:** Meaning preserved. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## VE-09 — Plan Retrieval for Computing Vocabulary
**ROLE:** Primary computing teacher. **CONTEXT:** Vocabulary and errors supplied. **TASK:** Create retrieval practice. **REQUIREMENTS:** Mix recognition, recall and application. **OUTPUT FORMAT:** Retrieval set, answers, follow-up. **QUALITY CHECKS:** Term-meaning alignment. **OPTIONAL CUSTOMISATION:** 5/10 minutes.

## VE-10 — Build a Misconception-to-Intervention Sequence
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Concept and pupil evidence supplied. **TASK:** Turn a diagnosed misconception into a short teaching sequence. **REQUIREMENTS:** Include discriminating check and transfer task. **OUTPUT FORMAT:** Diagnosis, explanation, task, check, intervention decision. **QUALITY CHECKS:** Evidence and construct alignment. **OPTIONAL CUSTOMISATION:** Individual/small group.
