# Digital Literacy & Productivity Workflows

**IDs:** DL-01 to DL-10

## DL-01 — Teach File Management
**ROLE:** Primary computing teacher. **CONTEXT:** Device/platform supplied. **TASK:** Teach purposeful file organisation. **REQUIREMENTS:** Do not assume interface details; include naming and retrieval principles. **OUTPUT FORMAT:** Lesson sequence and checklist. **QUALITY CHECKS:** Tool fidelity. **OPTIONAL CUSTOMISATION:** School platform.

## DL-02 — Teach Searching and Navigation
**ROLE:** Computing teacher. **CONTEXT:** Environment supplied. **TASK:** Teach efficient navigation and searching. **REQUIREMENTS:** Use accurate controls for the stated environment or keep instructions generic. **OUTPUT FORMAT:** Demonstration, practice, check. **QUALITY CHECKS:** Interface accuracy. **OPTIONAL CUSTOMISATION:** Browser/file system.

## DL-03 — Teach Digital Organisation
**ROLE:** Primary computing teacher. **CONTEXT:** Classroom workflow supplied. **TASK:** Design a digital organisation routine. **REQUIREMENTS:** Include naming, folders and retrieval; avoid unsupported platform features. **OUTPUT FORMAT:** Routine and pupil checklist. **QUALITY CHECKS:** Practicality. **OPTIONAL CUSTOMISATION:** Shared drive.

## DL-04 — Teach Productivity Tool Selection
**ROLE:** Computing teacher. **CONTEXT:** Task and available tools supplied. **TASK:** Help pupils choose an appropriate tool. **REQUIREMENTS:** Base recommendation on supplied capabilities, not invented features. **OUTPUT FORMAT:** Decision matrix. **QUALITY CHECKS:** Fitness for purpose. **OPTIONAL CUSTOMISATION:** School tools.

## DL-05 — Create a Digital Workflow
**ROLE:** Computing teacher. **CONTEXT:** Multi-step task supplied. **TASK:** Sequence an efficient digital workflow. **REQUIREMENTS:** Identify inputs, actions, outputs and review points. **OUTPUT FORMAT:** Numbered workflow. **QUALITY CHECKS:** Completeness. **OPTIONAL CUSTOMISATION:** Individual/group work.

## DL-06 — Diagnose Productivity Errors
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil workflow/error supplied. **TASK:** Diagnose the likely skill or conceptual issue. **REQUIREMENTS:** Use evidence and distinguish tool knowledge from planning problems. **OUTPUT FORMAT:** Evidence, diagnosis, check, intervention. **QUALITY CHECKS:** Evidence-based. **OPTIONAL CUSTOMISATION:** Year group.

## DL-07 — Teach Accessible Digital Working
**ROLE:** Inclusive computing teacher. **CONTEXT:** Tool and learner need supplied. **TASK:** Identify appropriate accessibility strategies. **REQUIREMENTS:** Use available, stated features or clearly label assumptions. **OUTPUT FORMAT:** Strategy table and practice task. **QUALITY CHECKS:** Accessibility and tool fidelity. **OPTIONAL CUSTOMISATION:** Learner profile.

## DL-08 — Evaluate a Digital Workflow
**ROLE:** Computing teacher. **CONTEXT:** Workflow and goal supplied. **TASK:** Evaluate efficiency, clarity and reliability. **REQUIREMENTS:** Use stated evidence and avoid unsupported performance claims. **OUTPUT FORMAT:** Criteria table and improvements. **QUALITY CHECKS:** Evidence alignment. **OPTIONAL CUSTOMISATION:** Pupil self-review.

## DL-09 — Adapt a Productivity Task
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original task and learner need supplied. **TASK:** Improve access while retaining the intended computing skill. **REQUIREMENTS:** Scaffold process without removing purposeful decision-making. **OUTPUT FORMAT:** Adapted task, scaffold, independence route, stretch. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## DL-10 — Retrieval and Re-teach Digital Literacy
**ROLE:** Primary computing teacher. **CONTEXT:** Skill gap supplied. **TASK:** Create a retrieval-to-reteach cycle. **REQUIREMENTS:** Target the diagnosed gap and include an independent exit check. **OUTPUT FORMAT:** Retrieval, modelling, practice, check. **QUALITY CHECKS:** Alignment. **OPTIONAL CUSTOMISATION:** Specify tool.
