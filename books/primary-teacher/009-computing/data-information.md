# Data & Information Workflows

**IDs:** DI-01 to DI-10

## DI-01 — Classify Data
**ROLE:** Primary computing teacher. **CONTEXT:** Data examples and year group supplied. **TASK:** Classify data using the stated categories. **REQUIREMENTS:** Explain the classification and avoid ambiguous categories. **OUTPUT FORMAT:** Table with reasons. **QUALITY CHECKS:** Conceptual accuracy. **OPTIONAL CUSTOMISATION:** Text/numbers/images.

## DI-02 — Explain Data Representation
**ROLE:** Computing teacher. **CONTEXT:** Representation supplied. **TASK:** Explain how information is represented digitally. **REQUIREMENTS:** Match technical depth to year group. **OUTPUT FORMAT:** Explanation and example. **QUALITY CHECKS:** Accuracy. **OPTIONAL CUSTOMISATION:** Binary/pixels/symbols.

## DI-03 — Explore Binary
**ROLE:** Primary computing teacher. **CONTEXT:** Year group and binary task supplied. **TASK:** Teach a suitable binary concept. **REQUIREMENTS:** Show place value or encoding explicitly; check calculations. **OUTPUT FORMAT:** Worked examples and pupil practice. **QUALITY CHECKS:** Numerical accuracy. **OPTIONAL CUSTOMISATION:** KS2.

## DI-04 — Organise Data for a Purpose
**ROLE:** Computing teacher. **CONTEXT:** Dataset or scenario supplied. **TASK:** Choose an appropriate structure for organising data. **REQUIREMENTS:** Preserve supplied values and explain design choices. **OUTPUT FORMAT:** Structure and rationale. **QUALITY CHECKS:** Data fidelity. **OPTIONAL CUSTOMISATION:** Table/list.

## DI-05 — Interpret a Dataset
**ROLE:** Computing teacher. **CONTEXT:** Dataset supplied. **TASK:** Identify patterns and answer questions. **REQUIREMENTS:** Do not invent values or infer unsupported causation. **OUTPUT FORMAT:** Findings, evidence and questions. **QUALITY CHECKS:** Data fidelity. **OPTIONAL CUSTOMISATION:** Spreadsheet data.

## DI-06 — Design a Data Collection Task
**ROLE:** Computing enquiry designer. **CONTEXT:** Question and year group supplied. **TASK:** Design a structured data-collection activity. **REQUIREMENTS:** Define fields, categories and recording method; consider privacy. **OUTPUT FORMAT:** Question, fields, procedure, template. **QUALITY CHECKS:** Fitness for purpose. **OPTIONAL CUSTOMISATION:** Classroom survey.

## DI-07 — Diagnose Data Misconceptions
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil response or dataset interpretation supplied. **TASK:** Diagnose misunderstanding. **REQUIREMENTS:** Distinguish representation, classification, reading-data and reasoning errors. **OUTPUT FORMAT:** Evidence, diagnosis, check, intervention. **QUALITY CHECKS:** Evidence-based. **OPTIONAL CUSTOMISATION:** Year group.

## DI-08 — Explain Data Quality
**ROLE:** Computing teacher. **CONTEXT:** Dataset supplied. **TASK:** Identify completeness, consistency or accuracy issues. **REQUIREMENTS:** Base claims on the supplied data. **OUTPUT FORMAT:** Quality-check table and actions. **QUALITY CHECKS:** Evidence fidelity. **OPTIONAL CUSTOMISATION:** Spreadsheet.

## DI-09 — Adapt a Data Task
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original data task and learner need supplied. **TASK:** Improve access while preserving data reasoning. **REQUIREMENTS:** Retain classification, representation or interpretation demand. **OUTPUT FORMAT:** Adaptation, scaffold, stretch. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## DI-10 — Retrieval and Re-teach Data Knowledge
**ROLE:** Primary computing teacher. **CONTEXT:** Concept and pupil errors supplied. **TASK:** Create a retrieval-to-reteach cycle. **REQUIREMENTS:** Target diagnosed gaps and include an exit check. **OUTPUT FORMAT:** Retrieval, reteach, practice, check. **QUALITY CHECKS:** Alignment. **OPTIONAL CUSTOMISATION:** Specify duration.
