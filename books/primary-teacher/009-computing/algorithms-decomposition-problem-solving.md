# Algorithms, Decomposition & Problem Solving Workflows

**IDs:** AD-01 to AD-10

## AD-01 — Decompose a Problem
**ROLE:** Computational-thinking teacher. **CONTEXT:** Problem supplied. **TASK:** Break it into manageable subproblems. **REQUIREMENTS:** Preserve dependencies and define the boundary of each subproblem. **OUTPUT FORMAT:** Decomposition map. **QUALITY CHECKS:** Completeness. **OPTIONAL CUSTOMISATION:** Year group.

## AD-02 — Sequence Instructions
**ROLE:** Primary computing teacher. **CONTEXT:** Goal supplied. **TASK:** Create precise ordered instructions. **REQUIREMENTS:** Make steps unambiguous and testable. **OUTPUT FORMAT:** Numbered algorithm. **QUALITY CHECKS:** No missing dependencies. **OPTIONAL CUSTOMISATION:** Unplugged task.

## AD-03 — Identify Selection
**ROLE:** Computing teacher. **CONTEXT:** Scenario supplied. **TASK:** Identify where a decision is required. **REQUIREMENTS:** State condition and possible outcomes. **OUTPUT FORMAT:** Decision table and pseudocode. **QUALITY CHECKS:** Logical completeness. **OPTIONAL CUSTOMISATION:** Beginner/advanced.

## AD-04 — Identify Iteration
**ROLE:** Computing teacher. **CONTEXT:** Repetitive task supplied. **TASK:** Identify and express repetition. **REQUIREMENTS:** State stopping condition where relevant. **OUTPUT FORMAT:** Algorithm and trace. **QUALITY CHECKS:** Termination logic. **OPTIONAL CUSTOMISATION:** Pseudocode.

## AD-05 — Test an Algorithm
**ROLE:** Computing teacher. **CONTEXT:** Algorithm supplied. **TASK:** Create cases that reveal errors. **REQUIREMENTS:** Include normal, boundary and relevant unusual cases; do not claim tests were run. **OUTPUT FORMAT:** Test table. **QUALITY CHECKS:** Coverage. **OPTIONAL CUSTOMISATION:** Code later.

## AD-06 — Trace an Algorithm
**ROLE:** Primary computing teacher. **CONTEXT:** Algorithm supplied. **TASK:** Trace state changes step by step. **REQUIREMENTS:** Preserve every supplied instruction. **OUTPUT FORMAT:** Trace table and final state. **QUALITY CHECKS:** Logical accuracy. **OPTIONAL CUSTOMISATION:** Variables supplied.

## AD-07 — Compare Problem-Solving Strategies
**ROLE:** Computing teacher. **CONTEXT:** Two supplied strategies. **TASK:** Compare correctness, clarity and suitability. **REQUIREMENTS:** Base judgement on actual strategies. **OUTPUT FORMAT:** Comparison and justified recommendation. **QUALITY CHECKS:** Evidence-based reasoning. **OPTIONAL CUSTOMISATION:** Pair work.

## AD-08 — Diagnose Algorithmic Misconceptions
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil algorithm/explanation supplied. **TASK:** Diagnose the likely reasoning error. **REQUIREMENTS:** Distinguish sequence, condition, repetition and decomposition issues. **OUTPUT FORMAT:** Evidence, diagnosis, discriminating task, intervention. **QUALITY CHECKS:** Diagnostic validity. **OPTIONAL CUSTOMISATION:** Year group.

## AD-09 — Adapt a Computational Problem
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original problem and learner need supplied. **TASK:** Improve access without reducing computational reasoning. **REQUIREMENTS:** Scaffold representation, not the core problem-solving demand. **OUTPUT FORMAT:** Adapted problem, scaffold, independence route, stretch. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## AD-10 — Retrieval and Re-teach Algorithms
**ROLE:** Primary computing teacher. **CONTEXT:** Concept and pupil errors supplied. **TASK:** Create a retrieval-to-reteach cycle. **REQUIREMENTS:** Target the diagnosed concept and include a fresh transfer check. **OUTPUT FORMAT:** Retrieval, reteach, guided task, transfer check. **QUALITY CHECKS:** Alignment. **OPTIONAL CUSTOMISATION:** Specify duration.
