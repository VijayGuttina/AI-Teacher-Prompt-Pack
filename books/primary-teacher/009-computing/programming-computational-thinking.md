# Programming & Computational Thinking Workflows

**IDs:** PT-01 to PT-10

## PT-01 — Explain a Programming Concept
**ROLE:** Primary computing teacher. **CONTEXT:** Concept, language/environment and year group supplied. **TASK:** Explain the concept accurately. **REQUIREMENTS:** Use age-appropriate terminology and do not invent language features. **OUTPUT FORMAT:** Explanation, example, check question. **QUALITY CHECKS:** Technical accuracy. **OPTIONAL CUSTOMISATION:** Language supplied.

## PT-02 — Write a Small Program
**ROLE:** Primary computing teacher. **CONTEXT:** Task, language and environment supplied. **TASK:** Produce a small program meeting the stated goal. **REQUIREMENTS:** Keep code age-appropriate; state assumptions; do not claim execution. **OUTPUT FORMAT:** Code, explanation, test cases. **QUALITY CHECKS:** Syntax plausibility and requirement coverage. **OPTIONAL CUSTOMISATION:** Scaffold level.

## PT-03 — Predict Program Output
**ROLE:** Computing teacher. **CONTEXT:** Code supplied. **TASK:** Predict the output and explain the trace. **REQUIREMENTS:** Follow the supplied code exactly. **OUTPUT FORMAT:** Step trace and predicted output. **QUALITY CHECKS:** Logical accuracy. **OPTIONAL CUSTOMISATION:** Add challenge.

## PT-04 — Debug Pupil Code
**ROLE:** Programming teacher. **CONTEXT:** Pupil code, expected behaviour and environment supplied. **TASK:** Diagnose and repair the code. **REQUIREMENTS:** Distinguish syntax, logic and requirement errors; explain the smallest useful fix. **OUTPUT FORMAT:** Diagnosis, corrected code, explanation, test cases. **QUALITY CHECKS:** Code fidelity. **OPTIONAL CUSTOMISATION:** Hint-first mode.

## PT-05 — Decompose a Programming Task
**ROLE:** Computational-thinking teacher. **CONTEXT:** Goal supplied. **TASK:** Break it into manageable subproblems. **REQUIREMENTS:** Preserve dependencies and avoid solving hidden requirements without stating them. **OUTPUT FORMAT:** Decomposition tree and sequence. **QUALITY CHECKS:** Completeness and logical order. **OPTIONAL CUSTOMISATION:** Pair programming.

## PT-06 — Design an Algorithm
**ROLE:** Computing teacher. **CONTEXT:** Problem supplied. **TASK:** Create an algorithm before coding. **REQUIREMENTS:** Include inputs, decisions, repetition where needed and expected outcome. **OUTPUT FORMAT:** Pseudocode or numbered algorithm. **QUALITY CHECKS:** Completeness and traceability. **OPTIONAL CUSTOMISATION:** Flowchart brief.

## PT-07 — Compare Algorithms
**ROLE:** Computing teacher. **CONTEXT:** Two supplied approaches. **TASK:** Compare clarity, efficiency at an age-appropriate level and correctness. **REQUIREMENTS:** Use actual supplied behaviour, not unsupported claims. **OUTPUT FORMAT:** Comparison and judgement. **QUALITY CHECKS:** Correctness. **OPTIONAL CUSTOMISATION:** KS2.

## PT-08 — Generate Programming Tests
**ROLE:** Computing teacher. **CONTEXT:** Program goal supplied. **TASK:** Create normal, boundary and error-oriented test cases appropriate to the task. **REQUIREMENTS:** State expected results without claiming tests were run. **OUTPUT FORMAT:** Test table. **QUALITY CHECKS:** Coverage. **OPTIONAL CUSTOMISATION:** Beginner/advanced.

## PT-09 — Diagnose Computational-Thinking Misconceptions
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil algorithm/code/explanation supplied. **TASK:** Identify likely conceptual difficulty. **REQUIREMENTS:** Distinguish sequencing, selection, iteration, decomposition or debugging issues using evidence. **OUTPUT FORMAT:** Evidence, diagnosis, hinge task, intervention. **QUALITY CHECKS:** Diagnostic validity. **OPTIONAL CUSTOMISATION:** Year group.

## PT-10 — Adapt a Programming Task
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original programming task and learner need supplied. **TASK:** Improve access while preserving computational thinking. **REQUIREMENTS:** Scaffold syntax or representation without removing the core reasoning. **OUTPUT FORMAT:** Adapted task, scaffold, independence route, stretch. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.
