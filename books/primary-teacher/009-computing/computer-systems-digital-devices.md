# Computer Systems & Digital Devices Workflows

**IDs:** CS-01 to CS-10

## CS-01 — Explain a Digital Device
**ROLE:** Primary computing teacher. **CONTEXT:** Device, year group and objective supplied. **TASK:** Explain what the device does and why. **REQUIREMENTS:** Use age-appropriate technical vocabulary; do not invent capabilities. **OUTPUT FORMAT:** Explanation, vocabulary, check question. **QUALITY CHECKS:** Technical accuracy. **OPTIONAL CUSTOMISATION:** Device supplied.

## CS-02 — Compare Digital Devices
**ROLE:** Computing teacher. **CONTEXT:** Two supplied devices. **TASK:** Compare functions and limitations. **REQUIREMENTS:** Use stated or verified characteristics; distinguish function from form. **OUTPUT FORMAT:** Comparison table and conclusion. **QUALITY CHECKS:** Like-for-like comparison. **OPTIONAL CUSTOMISATION:** KS1/KS2.

## CS-03 — Explain Input and Output
**ROLE:** Computing teacher. **CONTEXT:** Devices/components supplied. **TASK:** Classify and explain inputs and outputs. **REQUIREMENTS:** Explain information flow; avoid ambiguous examples. **OUTPUT FORMAT:** Classification table and explanation. **QUALITY CHECKS:** Conceptual accuracy. **OPTIONAL CUSTOMISATION:** Add sorting task.

## CS-04 — Explain Hardware and Software
**ROLE:** Computing teacher. **CONTEXT:** Examples supplied. **TASK:** Distinguish hardware from software. **REQUIREMENTS:** Use precise definitions and counterexamples. **OUTPUT FORMAT:** Explanation plus classification activity. **QUALITY CHECKS:** Accuracy. **OPTIONAL CUSTOMISATION:** Add misconception.

## CS-05 — Explain Operating-System Functions
**ROLE:** Primary computing teacher. **CONTEXT:** Year group and environment supplied. **TASK:** Explain relevant operating-system functions. **REQUIREMENTS:** Avoid assuming interface details that were not supplied. **OUTPUT FORMAT:** Explanation and examples. **QUALITY CHECKS:** Environment fidelity. **OPTIONAL CUSTOMISATION:** Device/OS supplied.

## CS-06 — Trace Information Through a System
**ROLE:** Computing teacher. **CONTEXT:** System or device scenario supplied. **TASK:** Trace input, processing, storage and output. **REQUIREMENTS:** Make each stage explicit. **OUTPUT FORMAT:** Flow sequence. **QUALITY CHECKS:** Logical accuracy. **OPTIONAL CUSTOMISATION:** Add diagram brief.

## CS-07 — Diagnose a Systems Misconception
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil explanation supplied. **TASK:** Identify the likely conceptual error. **REQUIREMENTS:** Infer only from evidence and include a discriminating check. **OUTPUT FORMAT:** Evidence, diagnosis, hinge question, response pathway. **QUALITY CHECKS:** Diagnostic validity. **OPTIONAL CUSTOMISATION:** Year group.

## CS-08 — Design a Device Investigation
**ROLE:** Computing enquiry designer. **CONTEXT:** Device/system and constraints supplied. **TASK:** Design a practical investigation. **REQUIREMENTS:** Specify observable evidence and avoid unsupported assumptions. **OUTPUT FORMAT:** Question, method, recording sheet. **QUALITY CHECKS:** Feasibility and safety. **OPTIONAL CUSTOMISATION:** Classroom devices.

## CS-09 — Adapt a Systems Task
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original task and learner need supplied. **TASK:** Improve access while preserving systems understanding. **REQUIREMENTS:** Retain technical vocabulary and reasoning. **OUTPUT FORMAT:** Adaptation, scaffold, independence route. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## CS-10 — Retrieval and Re-teach Systems Knowledge
**ROLE:** Primary computing teacher. **CONTEXT:** Concept and pupil errors supplied. **TASK:** Create a retrieval-to-reteach cycle. **REQUIREMENTS:** Target diagnosed gaps and include an exit check. **OUTPUT FORMAT:** Retrieval, reteach, guided practice, check. **QUALITY CHECKS:** Alignment. **OPTIONAL CUSTOMISATION:** Specify duration.
