# Networks & Connectivity Workflows

**IDs:** NC-01 to NC-10

## NC-01 — Explain a Computer Network
**ROLE:** Primary computing teacher. **CONTEXT:** Year group and objective supplied. **TASK:** Explain what a network is and why devices connect. **REQUIREMENTS:** Use accurate terminology; do not invent the school's network setup. **OUTPUT FORMAT:** Explanation, vocabulary, check question. **QUALITY CHECKS:** Technical accuracy. **OPTIONAL CUSTOMISATION:** Home/school example.

## NC-02 — Explain Network Components
**ROLE:** Computing teacher. **CONTEXT:** Components supplied. **TASK:** Explain relevant network hardware/functions. **REQUIREMENTS:** Distinguish device roles and avoid unsupported specifications. **OUTPUT FORMAT:** Component-function table. **QUALITY CHECKS:** Accuracy. **OPTIONAL CUSTOMISATION:** Add diagram.

## NC-03 — Compare Wired and Wireless Connections
**ROLE:** Computing teacher. **CONTEXT:** Scenario supplied. **TASK:** Compare connection methods. **REQUIREMENTS:** Consider reliability, mobility, range and context without absolutes. **OUTPUT FORMAT:** Comparison matrix and recommendation. **QUALITY CHECKS:** Balanced reasoning. **OPTIONAL CUSTOMISATION:** Classroom scenario.

## NC-04 — Explain Data Transfer
**ROLE:** Primary computing teacher. **CONTEXT:** Network scenario supplied. **TASK:** Explain at an age-appropriate level how data moves between connected devices. **REQUIREMENTS:** Avoid misleading literal models. **OUTPUT FORMAT:** Sequence and vocabulary. **QUALITY CHECKS:** Conceptual accuracy. **OPTIONAL CUSTOMISATION:** Analogy with caveat.

## NC-05 — Explain the Internet and the Web
**ROLE:** Computing teacher. **CONTEXT:** Year group supplied. **TASK:** Distinguish internet from web. **REQUIREMENTS:** Use simple but technically defensible language. **OUTPUT FORMAT:** Explanation and comparison. **QUALITY CHECKS:** Accuracy. **OPTIONAL CUSTOMISATION:** KS2.

## NC-06 — Diagnose Network Misconceptions
**ROLE:** Diagnostic computing teacher. **CONTEXT:** Pupil response supplied. **TASK:** Identify likely misunderstanding. **REQUIREMENTS:** Base diagnosis on evidence and use a discriminating check. **OUTPUT FORMAT:** Evidence, diagnosis, hinge question, intervention. **QUALITY CHECKS:** Diagnostic validity. **OPTIONAL CUSTOMISATION:** Add year group.

## NC-07 — Design a Network Diagram Brief
**ROLE:** Computing teacher. **CONTEXT:** Network scenario supplied. **TASK:** Specify a pupil-friendly network diagram. **REQUIREMENTS:** Label relationships and direction of relevant information flow; do not invent topology. **OUTPUT FORMAT:** Diagram brief and success criteria. **QUALITY CHECKS:** Logical accuracy. **OPTIONAL CUSTOMISATION:** Add symbols.

## NC-08 — Explain Network Reliability
**ROLE:** Computing teacher. **CONTEXT:** Connection scenario supplied. **TASK:** Explain possible causes of connectivity problems. **REQUIREMENTS:** Distinguish hypothesis from known cause; avoid pretending to diagnose an unobserved network. **OUTPUT FORMAT:** Possible causes and tests. **QUALITY CHECKS:** Evidence discipline. **OPTIONAL CUSTOMISATION:** Classroom troubleshooting.

## NC-09 — Adapt a Networks Task
**ROLE:** Inclusive computing teacher. **CONTEXT:** Original task and learner need supplied. **TASK:** Improve access while preserving network reasoning. **REQUIREMENTS:** Retain core concept and technical vocabulary. **OUTPUT FORMAT:** Adaptation, scaffold, stretch. **QUALITY CHECKS:** Construct preservation. **OPTIONAL CUSTOMISATION:** SEND/EAL.

## NC-10 — Retrieval and Re-teach Networks
**ROLE:** Primary computing teacher. **CONTEXT:** Network concepts and pupil errors supplied. **TASK:** Create a retrieval-to-reteach sequence. **REQUIREMENTS:** Target identified gaps and include an exit check. **OUTPUT FORMAT:** Retrieval, reteach, practice, check. **QUALITY CHECKS:** Alignment. **OPTIONAL CUSTOMISATION:** Specify duration.
