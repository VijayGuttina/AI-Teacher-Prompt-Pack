# Sources and Historical Evidence Workflows

## SE-01 — Source analysis
**Purpose:** Analyse a supplied historical source.
**Editable Variables:** Year group; source; enquiry question.
### ROLE
Act as an experienced primary History teacher.
### TASK
Separate what the source contains from what it may help establish about the enquiry.
### OUTPUT FORMAT
Observation; provenance; evidence; inference; limitation; questions.
### QUALITY CHECKS
Never invent provenance or context not supplied.

## SE-02 — Source provenance questions
**Purpose:** Investigate who created a source, when, where and why.
**Editable Variables:** Source; year group.
### ROLE
Act as a primary History specialist.
### TASK
Create provenance questions and explain how each may affect interpretation.
### OUTPUT FORMAT
Question; evidence; implication; limitation.
### QUALITY CHECKS
Avoid treating purpose or bias as automatically making a source useless.

## SE-03 — Source usefulness
**Purpose:** Judge usefulness for a specific enquiry.
**Editable Variables:** Source; enquiry question; year group.
### ROLE
Act as a primary History teacher.
### TASK
Evaluate usefulness in relation to the question, content and provenance.
### OUTPUT FORMAT
Useful because; limitations; overall judgement; evidence.
### QUALITY CHECKS
Usefulness must be question-specific.

## SE-04 — Source comparison
**Purpose:** Compare two sources about the same topic.
**Editable Variables:** Sources; enquiry question; year group.
### ROLE
Act as a primary History subject specialist.
### TASK
Identify agreement, difference and possible reasons without assuming contradiction where none exists.
### OUTPUT FORMAT
Source A; Source B; comparison; explanation; limitations.
### QUALITY CHECKS
Quote or paraphrase only supplied material and preserve meaning.

## SE-05 — Source inference
**Purpose:** Help pupils make justified inferences.
**Editable Variables:** Source; year group; question.
### ROLE
Act as a primary History teacher.
### TASK
Create a sequence from observation to inference using evidence from the source.
### OUTPUT FORMAT
What we can see/read; inference; evidence; alternative inference.
### QUALITY CHECKS
Clearly distinguish inference from direct source content.

## SE-06 — Source reliability discussion
**Purpose:** Explore reliability without reducing it to a binary label.
**Editable Variables:** Source; purpose; provenance; question.
### ROLE
Act as a primary History specialist.
### TASK
Create a nuanced reliability discussion appropriate to the year group.
### OUTPUT FORMAT
Evidence; factors; reliability judgement; limitations.
### QUALITY CHECKS
Reliability must be assessed in relation to what the source is being used to establish.

## SE-07 — Primary source handling
**Purpose:** Prepare a supplied primary source for classroom use.
**Editable Variables:** Source text/image; year group; objective.
### ROLE
Act as an experienced primary History teacher.
### TASK
Annotate the source for vocabulary, provenance, evidence and suitable questions without changing its historical meaning.
### OUTPUT FORMAT
Teacher notes; pupil version guidance; questions; glossary; caveats.
### QUALITY CHECKS
Do not silently modernise or rewrite historical evidence as an original source.

## SE-08 — Source pack curator
**Purpose:** Select a balanced source set for an enquiry.
**Editable Variables:** Enquiry question; year group; available sources.
### ROLE
Act as a primary History curriculum specialist.
### TASK
Recommend source types and explain what each can and cannot establish.
### OUTPUT FORMAT
Source list; purpose; evidential value; limitation; sequencing.
### QUALITY CHECKS
Do not fabricate archive references or quotations.

## SE-09 — Source misconception diagnosis
**Purpose:** Diagnose errors in pupils' use of historical evidence.
**Editable Variables:** Pupil response; source; enquiry question.
### ROLE
Act as a primary History assessment specialist.
### TASK
Identify whether the error concerns observation, inference, provenance, relevance or overclaiming.
### OUTPUT FORMAT
Observable error; category; evidence; diagnostic check; teaching response.
### QUALITY CHECKS
Base diagnosis on the supplied response.

## SE-10 — Adapt source analysis
**Purpose:** Make a source accessible while retaining evidence evaluation.
**Editable Variables:** Source; year group; access barrier.
### ROLE
Act as an experienced primary History teacher specialising in adaptive teaching.
### TASK
Adapt presentation, vocabulary support or recording while preserving the evidence pupils must evaluate.
### OUTPUT FORMAT
Barrier; adaptation; support; preserved source evidence; preserved demand; independence route.
### QUALITY CHECKS
Do not remove the very source features pupils need to analyse.
