# SEND Cognition, Learning & Executive Function

This family contains ten copy/paste-ready workflows for supporting cognition, learning and executive function in primary classrooms. The workflows focus on observable task demands and learning barriers rather than diagnostic assumptions. They support memory, attention, processing, planning, organisation, task initiation, inhibition, flexible thinking, checking and metacognition while protecting curriculum ambition and assessment validity.

## SEND-specific cognition and executive-function rules

Use these controls in every workflow:

- Start with the intended learning and actual task demand before selecting a support strategy.
- Treat executive-function support as classroom access and learning support, not as diagnosis or treatment.
- Use observable evidence such as work samples, task performance, classroom observations and supplied pupil information.
- Do not diagnose ADHD, dyslexia, dyspraxia, autism, intellectual disability, mental health conditions or any other condition from classroom behaviour or performance.
- Do not assume a diagnostic label predicts the same cognitive profile for every pupil.
- Distinguish attention, working memory, processing, retrieval, language, prior knowledge, motivation, task design, sensory access and emotional factors where the evidence allows.
- Never equate slow completion, movement, forgetfulness, unfinished work or apparent inattention with lack of ability or effort without evidence.
- Reduce unnecessary cognitive load while preserving the intended disciplinary thinking and curriculum demand.
- Make task structure visible without doing the thinking for the pupil.
- Use retrieval, rehearsal, modelling, chunking, worked examples, visual structure, checklists, planning tools and metacognitive prompts where they address the evidenced barrier.
- Build independence deliberately. Support should be faded when evidence shows that the pupil can perform the relevant process without it.
- Avoid permanent adult prompting or over-scaffolding that masks independent performance.
- Distinguish remembering a procedure from understanding why it works.
- Preserve the intended assessment construct. If a support changes the construct, state this clearly.
- Do not require disclosure of diagnosis, family circumstances, medical information or personal experiences.
- Do not invent EHCP provision, specialist recommendations, school policy, safeguarding procedures or clinical interventions.
- Keep strategies realistic for a primary classroom with finite time, staffing and resources.
- Use no em dash character in generated output.

## SEND-41: Analyse Cognition and Executive-Function Demands in a Learning Task

**AI model compatibility:** ChatGPT and comparable general-purpose models

**Typical generation time:** 45 to 75 seconds  
**Curriculum tags:** SEND, cognition, executive function, learning barriers, adaptive teaching

### ROLE

Act as an experienced primary teacher and SEND-informed learning specialist. Analyse cognitive and executive-function demands from the task itself rather than from a pupil label.

### CONTEXT

Year group: [YEAR_GROUP]

Subject: [SUBJECT]

Learning construct: [LEARNING_CONSTRUCT]

Task or activity: [TASK]

Observed pupil evidence: [OBSERVED_EVIDENCE]

Prior learning: [PRIOR_LEARNING]

Existing supports: [EXISTING_SUPPORTS]

### TASK

Analyse the cognitive and executive-function demands of the task and identify practical access barriers that may be interfering with learning.

### REQUIREMENTS

Analyse:

- attention demand
- working-memory demand
- processing demand
- retrieval demand
- sequencing
- planning
- task initiation
- inhibition or distraction control
- switching or flexibility
- organisation

- Potential barriers
- Access adaptations

**Example Input:** Year 5 science; pupils must read a short source, select relevant evidence, organise it and write a conclusion; one pupil repeatedly starts writing before identifying relevant evidence.

**Example Output excerpt:** Separate the scientific reasoning construct from the task-sequencing demand. Provide a visible planning sequence and check whether independent evidence selection improves before making further assumptions.

**Expected output length:** 900 to 1,400 words  
**Typical generation time:** 45 to 75 seconds

### CONTEXT

Year group: [YEAR_GROUP]

Subject: [SUBJECT]

Objective: [OBJECTIVE]

Learning construct: [LEARNING_CONSTRUCT]

Task: [TASK]

Observed difficulty: [OBSERVED_DIFFICULTY]

Essential information pupils must remember: [ESSENTIAL_INFORMATION]

### TASK

Design a working-memory support plan for the task.

### REQUIREMENTS

Separate:

1. information that should become retrievable through learning
2. information that can appropriately remain externally available
3. information that is incidental to the construct
4. information that must be held mentally because it is part of the intended learning

Use appropriate supports such as visual prompts, worked examples, chunking, rehearsal, retrieval cues, task cards or structured notes. Explain when each support should be available and when it should be reduced.

### OUTPUT FORMAT

Provide:

- Working-memory demand analysis
- Essential memory requirements
- External supports
- Teacher modelling
- Guided practice
- Independent practice
- Fading plan
- Assessment implications

### QUALITY CHECKS

Do not remove memory demands that are themselves the learning objective. Do not assume that every forgetting behaviour indicates a working-memory difficulty.

### OPTIONAL CUSTOMISATION

Add [RESOURCE_LIMITS], [TIME_AVAILABLE] and [ASSESSMENT_CONTEXT].

**Example Input:** Year 3 maths; pupils must solve multi-step problems and often forget the result from the first step while completing the second.

**Example Output excerpt:** Use a structured calculation record to retain intermediate results while keeping the multi-step mathematical reasoning requirement intact, then reduce the external support as accuracy and independence improve.

**Curriculum tags:** SEND, metacognition, self-monitoring, independence, learning strategies

### ROLE

Act as a primary teacher designing explicit metacognitive supports that help pupils plan, monitor and evaluate their own learning without creating excessive verbal or written demands.

### CONTEXT

Year group: [YEAR_GROUP]

Subject: [SUBJECT]

Objective: [OBJECTIVE]

Task: [TASK]

Current self-monitoring evidence: [CURRENT_EVIDENCE]

Existing prompts or tools: [EXISTING_TOOLS]

### TASK

Create a teachable self-monitoring routine aligned to the actual learning construct.

### REQUIREMENTS

Build the routine around:

**Plan → Do → Check → Explain → Improve**

For each stage specify a small number of useful prompts or actions. Include visual, verbal or written options where appropriate. Make clear how the teacher models the routine, how pupils practise it with support and how prompts are faded.

### OUTPUT FORMAT

- Pupil routine
- Prompt card or checklist
- Guided practice
- Independent use
- Fading plan
- Evidence of impact

### QUALITY CHECKS

### OPTIONAL CUSTOMISATION

Add [ASSESSMENT_CRITERIA], [RESPONSE_MODE] and [TIME_AVAILABLE].

**Example Input:** Year 5 maths; pupils often complete calculations without checking whether their answer is reasonable.

**Example Output excerpt:** Teach a short check routine focused on operation choice, calculation accuracy and reasonableness, then move from teacher-led prompts to an independent check card.
