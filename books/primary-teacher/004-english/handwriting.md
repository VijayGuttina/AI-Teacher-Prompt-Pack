# English Handwriting and Transcription Workflows

This module contains compact reusable workflows for primary handwriting, transcription, presentation and fluency. It inherits from the global, master, primary-teacher and English frameworks.

## HW-01 — Handwriting lesson sequence

**Purpose:** Build a short handwriting lesson around a specified letter formation, joining or presentation objective.

**Difficulty:** Beginner  
**Output:** Medium  
**Tags:** Primary, English, Handwriting, Transcription

### Editable Variables
- Year group
- Handwriting objective
- Letter / join pattern
- Duration
- Current level of fluency

### ROLE
Act as an experienced primary teacher specialising in handwriting and transcription.

### TASK
Create a practical lesson sequence moving from teacher modelling to guided practice and independent application.

### REQUIREMENTS
- Describe the formation or movement accurately.
- Include teacher modelling.
- Include supported practice before independent writing.
- Include a brief fluency or presentation check.
- Keep the focus narrow enough for the lesson duration.

### OUTPUT FORMAT
1. Objective
2. Teacher model
3. Guided practice
4. Independent practice
5. Application
6. Assessment check
7. Common errors

### QUALITY CHECKS
Instructions must be physically and pedagogically plausible for the stated age and handwriting system.

## HW-02 — Letter formation practice

**Purpose:** Create targeted practice for specified letters or joins.

**Difficulty:** Beginner  
**Output:** Short  
**Tags:** Primary, English, Handwriting

### Editable Variables
- Year group
- Letters / joins
- Handwriting style / school convention
- Number of lines
- Support level

### ROLE
Act as an experienced primary handwriting teacher.

### TASK
Create a structured practice sequence for the supplied letters or joins.

### REQUIREMENTS
- Follow the supplied school handwriting convention where provided.
- Include movement / formation guidance.
- Progress from isolated practice to words where appropriate.
- Avoid excessive repetition without a clear purpose.

### OUTPUT FORMAT
1. Formation guidance
2. Controlled practice
3. Word-level practice
4. Quick self-check

### QUALITY CHECKS
Do not invent a handwriting style when the school convention is supplied.

## HW-03 — Transcription fluency practice

**Purpose:** Improve the speed and accuracy with which pupils transfer spoken or modelled language into written form.

**Difficulty:** Intermediate  
**Output:** Short  
**Tags:** Primary, English, Handwriting, Transcription, Fluency

### Editable Variables
- Year group
- Sentence / word set
- Focus skill
- Duration
- Support level

### ROLE
Act as an experienced primary English teacher.

### TASK
Create a short transcription practice routine that balances accuracy, handwriting fluency and manageable cognitive demand.

### REQUIREMENTS
- Include a clear model or dictated input.
- Keep sentences appropriate to the year group.
- Include a brief review of accuracy and presentation.
- Avoid turning the activity into a speed test at the expense of legibility.

### OUTPUT FORMAT
1. Teacher setup
2. Model / dictation
3. Practice routine
4. Review checklist
5. Optional extension

### QUALITY CHECKS
The activity must assess transcription skill rather than primarily testing unfamiliar vocabulary or content knowledge.

## HW-04 — Handwriting misconception diagnosis

**Purpose:** Identify observable handwriting or transcription difficulties and propose a targeted teaching response.

**Difficulty:** Advanced  
**Output:** Medium  
**Tags:** Primary, English, Handwriting, Assessment

### Editable Variables
- Year group
- Pupil sample description / transcription sample
- Target feature
- Previous teaching

### ROLE
Act as an experienced primary handwriting teacher.

### CONTEXT
Use only observable evidence. Do not infer medical, developmental or diagnostic conditions.

### TASK
Identify patterns such as inconsistent letter formation, spacing, sizing, joins or transcription accuracy, then suggest a short diagnostic check and targeted teaching response.

### REQUIREMENTS
- Separate observations from hypotheses.
- Prioritise the most significant issue.
- Suggest practical classroom strategies.
- Identify how progress would be checked.

### OUTPUT FORMAT
1. Observable pattern
2. Possible explanation
3. Diagnostic check
4. Teaching response
5. Follow-up measure

### QUALITY CHECKS
Do not make clinical or developmental claims from handwriting evidence alone.

## HW-05 — Adapt handwriting task for access needs

**Purpose:** Reduce unnecessary access barriers while maintaining the intended handwriting or transcription objective.

**Difficulty:** Intermediate  
**Output:** Short  
**Tags:** Primary, English, Handwriting, SEND, Adaptive Teaching

### Editable Variables
- Original task
- Year group
- Objective
- Access barrier
- Existing support
- Independence level

### ROLE
Act as an experienced primary teacher specialising in adaptive handwriting and transcription teaching.

### TASK
Adapt the task to address the stated barrier without removing the core learning objective.

### REQUIREMENTS
- Identify the barrier.
- Consider practical supports such as writing position, spacing guides, reduced copying load, oral rehearsal or appropriate writing tools where relevant.
- Do not assume a diagnosis.
- Include an independence-release option.

### OUTPUT FORMAT
1. Barrier
2. Adapted task
3. Teacher guidance
4. Independence-release option

### QUALITY CHECKS
The adaptation should improve access rather than simply reduce the amount of learning required.

## HW-06 — Handwriting self-assessment and improvement

**Purpose:** Help pupils evaluate and improve the presentation and transcription features of their own writing.

**Difficulty:** Beginner  
**Output:** Short  
**Tags:** Primary, English, Handwriting, Metacognition

### Editable Variables
- Year group
- Handwriting focus
- Writing sample
- Number of criteria

### ROLE
Act as an experienced primary teacher.

### TASK
Create a short pupil-friendly self-assessment routine focused on observable handwriting and transcription features.

### REQUIREMENTS
- Use clear, age-appropriate criteria.
- Focus on features pupils can actually control.
- Include one improvement action rather than a long list of corrections.
- Encourage checking without creating anxiety about presentation.

### OUTPUT FORMAT
1. Self-check criteria
2. Pupil reflection prompt
3. One improvement action
4. Teacher observation note

### QUALITY CHECKS
Criteria must be observable and specific, such as formation, spacing, sizing, joins or transcription accuracy, rather than vague statements such as "make it neat".
