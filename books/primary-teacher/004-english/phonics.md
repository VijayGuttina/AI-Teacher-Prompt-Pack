# English Phonics Workflows

This module contains compact reusable workflows for primary phonics teaching, assessment and intervention. It inherits from the global, master, primary-teacher and English frameworks.

## PH-01 — Phonics lesson sequence

**Purpose:** Build a focused phonics lesson around a stated grapheme-phoneme correspondence or decoding objective.

**Difficulty:** Intermediate  
**Output:** Medium  
**Tags:** Primary, English, Phonics, Lesson Planning

### Editable Variables
- Year group / phase
- Target GPC
- Word set
- Prior knowledge
- Lesson duration
- Programme / school sequence

### ROLE
Act as an experienced primary phonics teacher. Follow the supplied school's phonics programme or sequence where one is provided.

### TASK
Create a short, systematic phonics lesson moving through review, explicit teaching, guided practice and application.

### REQUIREMENTS
- State the target GPC or decoding skill precisely.
- Include oral rehearsal and teacher modelling.
- Include blending and/or segmenting as appropriate.
- Include cumulative review where appropriate.
- Keep the sequence manageable for the stated age and lesson length.

### OUTPUT FORMAT
1. Objective
2. Review
3. Explicit teaching
4. Guided practice
5. Word reading / decoding
6. Application in sentence or text
7. Quick assessment
8. Misconceptions

### QUALITY CHECKS
Check every word against the stated phonics knowledge. Do not introduce untaught correspondences unless explicitly labelled as challenge material.

## PH-02 — Grapheme-phoneme correspondence practice

**Purpose:** Create targeted practice for a specified GPC.

**Difficulty:** Beginner  
**Output:** Short  
**Tags:** Primary, English, Phonics, GPC

### Editable Variables
- Target GPC
- Phase / year group
- Number of items
- Known GPCs
- Difficulty

### ROLE
Act as an experienced systematic phonics teacher.

### TASK
Create graduated practice for recognising and applying the supplied grapheme-phoneme correspondence.

### REQUIREMENTS
- Include recognition and application.
- Use only appropriate known correspondences plus clearly identified target content.
- Include teacher answers.
- Include a brief oral rehearsal component where useful.

### OUTPUT FORMAT
1. Sound / grapheme review
2. Recognition items
3. Word-reading items
4. Short application
5. Answers

### QUALITY CHECKS
Verify that each item uses the intended correspondence accurately.

## PH-03 — Blending and segmenting practice

**Purpose:** Strengthen decoding and encoding through blending and segmenting.

**Difficulty:** Beginner  
**Output:** Short  
**Tags:** Primary, English, Phonics, Blending, Segmenting

### Editable Variables
- Phase / year group
- Known GPCs
- Target words
- Number of items
- Support level

### ROLE
Act as an experienced primary phonics teacher.

### TASK
Create a short sequence of blending and/or segmenting activities matched to the supplied phonics knowledge.

### REQUIREMENTS
- Distinguish blending from segmenting.
- Include teacher modelling.
- Progress from supported to independent practice.
- Use decodable words appropriate to the supplied knowledge.

### OUTPUT FORMAT
1. Teacher model
2. Oral practice
3. Word-level practice
4. Independent check
5. Answers

### QUALITY CHECKS
Do not include words requiring GPCs outside the stated knowledge unless explicitly labelled.

## PH-04 — Decodable text and application

**Purpose:** Provide a short decodable reading application using specified phonics knowledge.

**Difficulty:** Intermediate  
**Output:** Short  
**Tags:** Primary, English, Phonics, Decodable Text

### Editable Variables
- Phase / year group
- Known GPCs
- Target words
- Length
- Topic

### ROLE
Act as an experienced primary phonics teacher and early reading specialist.

### TASK
Create a short decodable text that gives pupils meaningful practice using the supplied phonics knowledge.

### REQUIREMENTS
- Keep the text genuinely decodable against the supplied knowledge, apart from clearly identified unavoidable high-frequency words.
- Use natural, meaningful sentences.
- Include a small number of comprehension checks.
- Do not sacrifice readability merely to force target words into every sentence.

### OUTPUT FORMAT
1. Decodable text
2. Target words / GPCs
3. High-frequency words if applicable
4. Two to four comprehension questions
5. Teacher answer guidance

### QUALITY CHECKS
Audit the text word by word for phonics compatibility with the stated knowledge.

## PH-05 — Phonics assessment check

**Purpose:** Create a quick formative assessment of decoding or encoding knowledge.

**Difficulty:** Intermediate  
**Output:** Short  
**Tags:** Primary, English, Phonics, Assessment

### Editable Variables
- Phase / year group
- Target GPCs
- Known GPCs
- Assessment focus
- Number of items

### ROLE
Act as a primary phonics assessment specialist.

### TASK
Create a brief assessment that identifies whether pupils can recognise, decode and/or encode the target knowledge.

### REQUIREMENTS
- Include items that distinguish secure knowledge from guessing.
- Include real and, where appropriate, pseudo-words.
- Provide a simple recording format.
- Identify what each error may indicate without presenting an inferred cause as certain.

### OUTPUT FORMAT
1. Teacher instructions
2. Assessment items
3. Recording grid
4. Answer key
5. Error-pattern guidance
6. Suggested next teaching step

### QUALITY CHECKS
Assessment items must test the stated phonics knowledge rather than unrelated vocabulary knowledge.

## PH-06 — Phonics misconception diagnosis

**Purpose:** Analyse decoding or encoding errors and propose a targeted diagnostic response.

**Difficulty:** Advanced  
**Output:** Medium  
**Tags:** Primary, English, Phonics, Assessment, Intervention

### Editable Variables
- Phase / year group
- Target GPCs
- Pupil responses
- Error patterns
- Recent teaching

### ROLE
Act as an experienced primary phonics intervention teacher.

### CONTEXT
Use the supplied evidence only. Treat possible causes as hypotheses.

### TASK
Identify observable error patterns, suggest plausible misconceptions, design a quick diagnostic check and recommend a targeted teaching response.

### REQUIREMENTS
- Separate observation from inference.
- Consider GPC recognition, blending, segmenting and memory where evidence permits.
- Avoid labels about the pupil.
- Prioritise one or two high-impact next steps.

### OUTPUT FORMAT
1. Observed pattern
2. Possible explanation
3. Evidence
4. Diagnostic check
5. Targeted teaching response
6. Follow-up check

### QUALITY CHECKS
Do not claim a cause that cannot be established from the supplied evidence.

## PH-07 — Phonics intervention sequence

**Purpose:** Create a short targeted intervention sequence following identified phonics difficulty.

**Difficulty:** Advanced  
**Output:** Medium  
**Tags:** Primary, English, Phonics, Intervention

### Editable Variables
- Phase / year group
- Identified gap
- Known secure knowledge
- Intervention duration
- Group size
- Programme constraints

### ROLE
Act as an experienced primary phonics intervention teacher.

### TASK
Design a focused intervention sequence that reteaches the identified knowledge, provides repeated successful practice and checks transfer.

### REQUIREMENTS
- Begin with secure prerequisite knowledge.
- Use explicit modelling and guided practice.
- Provide cumulative repetition.
- Include a short transfer check.
- Align with the school's phonics programme where supplied.

### OUTPUT FORMAT
1. Identified gap
2. Prerequisite check
3. Intervention sequence
4. Practice items
5. Transfer check
6. Exit criteria

### QUALITY CHECKS
The intervention must target the identified gap rather than adding unrelated phonics content.

## PH-08 — Adapt phonics activity for access needs

**Purpose:** Adapt a phonics task to reduce unnecessary access barriers while preserving the decoding or encoding objective.

**Difficulty:** Intermediate  
**Output:** Short  
**Tags:** Primary, English, Phonics, SEND, EAL, Adaptive Teaching

### Editable Variables
- Original activity
- Phase / year group
- Target GPCs
- Access barrier
- Existing support
- Independence level

### ROLE
Act as an experienced primary teacher specialising in adaptive phonics teaching.

### TASK
Adapt the supplied activity to address the stated access barrier while preserving the target phonics knowledge.

### REQUIREMENTS
- Identify the barrier being addressed.
- Use practical supports such as visual structure, reduced extraneous language, oral rehearsal or controlled item quantity where appropriate.
- Do not assume a diagnosis.
- Include a route toward increasing independence.

### OUTPUT FORMAT
1. Barrier
2. Adapted activity
3. Teacher guidance
4. Independence-release option

### QUALITY CHECKS
The adaptation must improve access without replacing the phonics objective.
