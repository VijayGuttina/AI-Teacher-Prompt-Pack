# AI Teacher Prompt Library
# Project Roadmap

**Version:** 1.0.0

**Status:** Active

**Last Updated:** 4 August 2026

---

# Vision

Create the world's most comprehensive collection of professional AI prompt libraries for educators.

The project will deliver premium, evidence-informed, classroom-ready prompt packs covering teaching, leadership, assessment, communication and school improvement.

The repository will remain the single source of truth for every publication.

---

# Success Criteria

The project will be considered successful when it achieves the following objectives:

- Publish a complete collection of premium prompt packs.
- Maintain consistent editorial quality across every publication.
- Ensure every prompt follows the approved prompt structure.
- Generate professionally formatted DOCX and PDF editions from Markdown.
- Build a reusable publishing workflow for future releases.

---

# Guiding Principles

- Quality before quantity.
- Markdown is the master source.
- One editorial standard across every publication.
- Every prompt must be immediately usable.
- Every release must be commercially publishable.

# Editorial Workflow

For every chapter:

1. Generate content.
2. Review against `PROMPT_GUIDELINES.md`.
3. Check formatting against `STYLE_GUIDE.md`.
4. Save to repository.
5. Commit changes.
6. Update `CHANGELOG.md`.
7. Mark milestone progress.
8. Build preview if required.

# Quality Gates

A publication cannot be released until:

- Every prompt passes editorial review.
- Prompt numbering is sequential.
- Internal cross references are checked.
- UK English spelling is verified.
- Markdown validation passes.
- DOCX export is reviewed.
- PDF export is reviewed.
- Front and back matter are complete.
- Version number is updated.
- Changelog is updated.

# Risk Register

| Risk | Mitigation |
|------|------------|

| Formatting drift | Enforce `STYLE_GUIDE.md` |
| Large chapter files | Keep chapters logically organised |
| Publishing errors | Follow `BUILD.md` and quality gates |
| Scope growth | Track through roadmap and milestones |
