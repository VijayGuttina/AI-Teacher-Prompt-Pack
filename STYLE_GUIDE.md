# AI Teacher Prompt Library
# Editorial Style Guide

**Version:** 1.0.0

**Status:** Approved

**Applies To:** Every book, prompt, template and supporting document within this repository.

---

# Purpose

This document defines the editorial standards for the AI Teacher Prompt Library.

It exists to ensure every book feels like it has been written by a single professional author, regardless of when content is created.

All contributors must follow this guide.

---

# Guiding Principles

Every document should be:

- Professional
- Practical
- Teacher-focused
- Evidence-informed
- Easy to read
- Easy to navigate
- Consistent
- Commercially publishable

The entire library should read like a premium educational publication rather than a collection of unrelated prompts.

---

# English Standard

All content must use **UK English**.

Examples:

✓ organisation

✓ behaviour

✓ modelling

✓ programme

✓ specialising

Never use American spellings.

Incorrect examples:

✗ organization

✗ behavior

✗ modeling

✗ program (unless referring to software)

---

# Tone of Voice

Write as an experienced education consultant.

The tone should be:

- Professional
- Helpful
- Clear
- Practical
- Confident
- Respectful
- Encouraging

Avoid:

- Marketing hype
- Exaggeration
- Buzzwords
- Slang
- Humour unless intentionally included
- Overly academic language

---

# Audience

Primary audience:

Teachers.

Secondary audience:

- Teaching Assistants
- Middle Leaders
- Senior Leaders
- Curriculum Leaders
- SENCOs
- Tutors
- Student Teachers
- School Improvement Teams

Always assume readers are busy professionals looking for immediately usable resources.

# File Naming

Use lowercase.

Use hyphens.

Never use spaces.

Examples:

primary-teacher.md

lesson-planning.md

guided-reading.md

Avoid:

PrimaryTeacher.md

Lesson Planning.md

English.doc

---

# Chapter Naming

Use three-digit numbering.

Examples:

000-front-matter.md

001-introduction.md

002-how-to-use.md

003-general-teaching.md

004-english.md

999-index.md

Do not renumber chapters once published.

---

# Prompt Numbering

Prompt numbering is unique within each book.

Example:

Prompt 001

Prompt 002

Prompt 003

...

Prompt 400

Never reuse prompt numbers.

---

# Heading Structure

Use consistent Markdown headings.

```
# Book Title

## Chapter

### Prompt Title

#### Optional subsection
```

Never skip heading levels.

Do not use more than four heading levels.

---

# Paragraph Length

Keep paragraphs short.

Target:

2–5 sentences.

Avoid long blocks of text.

---

# Lists

Prefer bullet lists.

Example:

- Learning objectives
- Success criteria
- Teacher modelling

Numbered lists should only be used where sequence matters.

---

# Tables

Use tables for:

- Comparisons
- Checklists
- Timelines
- Planning
- Assessment criteria

Do not use tables purely for visual decoration.

---

# Typography

Use:

**Bold**

for important concepts.

Use *italics*

sparingly for emphasis.

Avoid excessive formatting.

Never underline text.

---

# Capitalisation

Use sentence case.

Correct:

Primary teacher prompt pack

Incorrect:

Primary Teacher Prompt Pack

Exception:

Book titles may use Title Case.

---

# Numbers

Use numerals for:

Years

Lesson durations

Percentages

Examples:

30 minutes

Year 4

10 questions

Spell out small numbers in running text where appropriate.

---

# Dates

Format:

3 August 2026

Never use:

08/03/26

---

# Time

Examples:

09:00

14:30

45 minutes

---

# Educational Terminology

Preferred terminology:

Teacher modelling

Retrieval practice

Adaptive teaching

Assessment for learning

Success criteria

Learning objective

Misconceptions

Scaffolding

Metacognition

Avoid outdated terminology where better alternatives exist.

---

# Evidence-Based Practice

Prompts should align with recognised educational research where appropriate.

Examples include:

- Rosenshine's Principles
- Retrieval Practice
- Cognitive Load Theory
- Spaced Practice
- Interleaving
- Formative Assessment
- Bloom's Taxonomy
- Universal Design for Learning (UDL)
- Adaptive Teaching

Do not force references when they are irrelevant.

---

# Prompt Layout

Every prompt must follow the structure defined in:

PROMPT_GUIDELINES.md

Do not deviate.

---

# Examples

Where appropriate include:

Worked examples

Model answers

Teacher examples

Sample outputs

Examples should improve understanding rather than increase length unnecessarily.

---

# Accessibility

Use:

Clear headings

Short paragraphs

Bulleted lists

Logical structure

Simple language

Avoid:

Large walls of text

Dense paragraphs

Unexplained jargon

---

# Inclusive Language

Use inclusive language throughout.

Avoid stereotypes.

Respect diversity.

Represent a broad range of learners and school contexts.

---

# Curriculum References

Where relevant:

Reference the National Curriculum for England.

If another curriculum is specified, adapt accordingly.

Do not assume all readers follow the same curriculum.

---

# Safeguarding

Where prompts relate to:

Wellbeing

Behaviour

Relationships

Online safety

Mental health

Personal information

Always encourage safe, age-appropriate practice.

Never provide advice that conflicts with safeguarding responsibilities.

---

# Prompt Titles

Titles should:

Describe the outcome.

Examples:

Create a Complete Guided Reading Lesson

Generate SATs Revision Questions

Write End-of-Year Reports

Avoid:

Reading Prompt

Lesson Generator

Worksheet

---

# Cross References

Where possible, include:

Related Prompts

to encourage readers to explore connected content.

---

# Consistency

Terminology must remain consistent across every book.

For example:

Always use

Learning Objective

Never alternate between:

Objective

Goal

Outcome

Aim

unless context requires it.

---

# Markdown Standards

Use standard Markdown only.

Avoid HTML.

Avoid embedded styling.

Keep files compatible with:

GitHub

VS Code

Pandoc

Markdown editors

---

# Images

Images should be stored in:

assets/images/

Use descriptive filenames.

Example:

guided-reading-example.png

---

# File Size

Aim for:

1 chapter = 20–60 prompts

If a chapter exceeds approximately 250 printed pages, split it into logical sections.

---

# Version Control

Every significant update should include:

Version number

Date

Summary

Maintain changes through Git commits.

---

# Editorial Checklist

Before approving any new content confirm that it:

✓ Uses UK English

✓ Follows PROMPT_GUIDELINES.md

✓ Uses the correct heading hierarchy

✓ Uses consistent terminology

✓ Is free from spelling mistakes

✓ Is free from grammar mistakes

✓ Uses consistent formatting

✓ Includes cross references where appropriate

✓ Is classroom practical

✓ Is commercially publishable
